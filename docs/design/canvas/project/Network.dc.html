Now, no Wi-Fi restart. Kicks the station if it is connected and refuses it from then on. Other stations are not touched. Gone after the next Wi-Fi restart.
For a time. Kick and ban for N seconds, then the station may join again: a timed outage for one device.
Saved. Written to the Wi-Fi config, survives reboot. Applying it restarts Wi-Fi for every station.
# panel: block now, no Wi-Fi restart
hostapd_cli -i phy0-ap0 deny_acl ADD_MAC f4:12:fa:f3:57:68
# "For 60 s" instead:
ubus call hostapd.phy0-ap0 del_client '{"addr":"f4:12:fa:f3:57:68","reason":5,"deauth":true,"ban_time":60000}'
# "Saved" instead:
uci set wireless.default_radio0.macfilter='deny'; uci add_list wireless.default_radio0.maclist='f4:12:fa:f3:57:68'
uci commit wireless; wifi up radio0
Two different tests: blocked here = the panel cannot join Wi-Fi at all. "Gets an address" off in the table above = the panel joins Wi-Fi but gets no IP.
