# v1.1a Leftovers Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close what the v1.0 reviews left open: issue #77's minors, the v1.0c plan's 1.x list, the 0.8.2 image
library's user-visible and robustness minors, one new VLAN matrix bug, an axe check, and the docs leftovers. No
router is touched.

**Architecture:** Each fix is a local change in the module that owns the behaviour, with a test that fails first. Two
changes reach further:
- Remove from the app asks every service whether it holds the router (Task 3).
- A capture streams on an SSH connection of its own (Task 4).

The axe check adds one e2e spec and one dev dependency (Task 10).

**Tech Stack:** Python 3.13, FastAPI, pydantic 2, asyncio, httpx, pytest (asyncio auto), ruff (line 110, `S` on),
mypy strict, React 19, TanStack Query, vitest, Testing Library, Playwright, `@axe-core/playwright`.

**Spec:** `docs/superpowers/specs/2026-11-03-openwrt-gui-design.md` (§6 Safety, §7 screens, §12 roadmap) and
`docs/superpowers/specs/2026-11-16-image-library-design.md`.

**Rulings made while writing the plan** (they need no answer; each says what it costs if wrong):
- **R1 (#77 minor 8):** a refused uci script after the include file was written does not delete the file. An
  existing include may already name that path, and deleting it would remove a saved table. The error names the file
  instead, and the result says `applied` (something was written). *Cost if wrong:* a stray file in `/etc/owg/nft`,
  named on screen.
- **R2 (#27):** a numeric `AT+COPS?` answer (format 2) shows as "42501 (network code)", not as an operator name.
  *Cost if wrong:* one string.
- **R3 (#35):** a kept path outside `/etc` is still saved, because sysupgrade keeps it. The save answer warns that
  this app's restore puts back `/etc` only. *Cost if wrong:* a refusal would be one line.
- **R4 (#36):** the Reset confirmation compares the typed name trimmed and case-insensitively. The "alone on this
  PC" tick stays. *Cost if wrong:* the old exact match is one line.
- **R5 (#77 minor 13):** the app's handler keeps the traceback (it names the request). uvicorn's own "Exception in
  ASGI application" record is dropped by a logging filter. *Cost if wrong:* a second traceback line in the log.
- **R6 (#4):** the firewall read takes the app's ingress devices from the fault records. It reads them only when an
  ingress qdisc is listed, so a normal read sends no extra command and the budget rows do not move. *Cost if wrong:*
  one more command on routers with an ingress qdisc.

## Global Constraints

- **Test first:** a change without a test that failed before it is not done (AGENTS.md).
- **No router access:** nothing in this plan runs on AP2 or any bench router.
- **Reads:**
  - background reads use `t.run` directly, never `run_audited`;
  - every new read constant passes `is_read_only_command`;
  - recorded AP2 commands (`tests/fixtures/ap2/*.json`) replay by exact string, so no existing command text changes.
- **Writes:** go through `ApplyRunner.run_planned` or `run_audited`; Bench Guard refuses them during a harness run
  (`GuardLocked`, 423). This plan adds no write command.
- **GitHub:** nothing is pushed and no GitHub object is created without Dmitry's explicit go. Branches are never
  deleted.
- **Public repo:** no real keys, passwords, names, neighbour MACs or SSIDs in fixtures, tests or docs. Test MACs are
  `02:00:00:…` or the simulator's own.
- **Scripts** run inside `D:\Essence_SC` or `C:\Essence_SC` (SentinelOne).
- **Style:**
  - ruff line length 110, ruff `S` on, mypy strict, functions under 50 lines; oxlint and `tsc -b` clean.
  - Source and test comments name no person: they cite "the final review", a ledger or a date.
- **API model changes:** after one, run `uv run python tools/dump_openapi.py && cd frontend && npm run gen:api`, and
  commit `frontend/src/api/schema.ts` with it.
- **CHANGELOG:** one line per task under `[Unreleased]`: `### Fixed` for Tasks 1-9, `### Added` for Task 10.
  Task 11's ROADMAP change gets no line.
- **pytest groups:** `tests/unit/wifi` and `tests/unit/api` clash when mixed in one pytest call. Run them separately;
  the full suite from the root is fine.
- **The gate**, before the review and after the fix pass:
  - `uv run ruff check . && uv run ruff format --check . && uv run mypy`
  - `uv run pytest`: everything passes; coverage stays at 95% or more.
  - The schema check: dump, `gen:api`, then `git diff --exit-code frontend/src/api/schema.ts`.
  - `cd frontend && npm run lint && npm run build && npm test && npm run e2e` (never two e2e runs at once).
  - The key and name scan of the branch's added lines.

## Review Focus

1. **Remove from the app (Task 3):** a router whose capture, flash or step-through ended must be removable again,
   and a router that is unreachable must stay removable when nothing is known to run on it. The armed-fault check
   uses the last status the poller read; with no status, it does not block.
2. **A capture's own connection (Task 4):** the connection is closed on every end (stop, error, Wireshark closed,
   start failing after it opened), and mon0's setup and removal still go through the pooled connection under the
   write lock.
3. **The image library's parallel fetch (Task 7):** one slow or failing `profiles.json` must not stop the others, the
   overall deadline must leave a partial catalog with a skipped count, and the lock still allows one catalog read at
   a time.
4. **The facts join (Task 1, #77 minor 7):** a caller with the same description still shares the read (the v1.0c
   test stays green), and a read started for an old description is never cached for the new one.
5. **axe (Task 10):** the check must fail on a real serious violation (prove it once with a broken label), and must
   not depend on timing: each screen is checked after its main heading is visible.

`flash.running`, `captures.live`-like state, `statuses`). Task 4 changes only `capture/service.py`. Tasks 7 and 8 both
