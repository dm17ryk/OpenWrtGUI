# OpenWrtGUI v0.1 Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship OpenWrtGUI 0.1.0: an installable Windows app that adds bench routers (password once, then its own SSH key), reads what each router says about itself, shows a read-only dashboard, respects Bench Guard, keeps an audit log, offers a terminal, updates itself from GitHub Releases, and comes with the full professional repo setup (CI, pre-release and release pipelines, wiki, templates, docs).

**Architecture:** A Python package (`src/openwrtgui`) runs FastAPI on 127.0.0.1 with a per-launch token and opens it in a pywebview (Edge WebView2) window. Routers are reached only through asyncssh, ubus first; a replay transport built from recorded AP2 output doubles as the router simulator for tests, e2e and screenshots. The React + TypeScript UI (`frontend/`) is built at release time and bundled by PyInstaller (onedir) into a per-user Inno Setup installer.

**Tech Stack:** Python 3.13 (uv), FastAPI, uvicorn, websockets, asyncssh, pywebview, psutil, httpx, pydantic 2; React 19, TypeScript, Vite, TanStack Query, react-router (HashRouter), xterm.js, vitest, Playwright; PyInstaller, Inno Setup 6; GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-03-openwrt-gui-design.md` (approved 2026-11-03). Executors read the spec sections each task names.

## Review Focus

1. A router that powers off or drops off the LAN mid-session: the dashboard marks it unreachable with the time, keeps the others live, and reconnects with backoff, with no stack traces (Task 8 test `test_unreachable_router_backs_off_and_reports_offline`, Task 13 test `test_poll_marks_offline_and_keeps_others`).
2. A router reflashed since it was added (new host key): the app refuses to connect and shows the old and new fingerprints, and the user can re-pin only through the wizard (Task 5 test `test_changed_host_key_is_refused_with_both_fingerprints`).
3. A data or install folder with spaces or non-ASCII characters (OneDrive paths such as `C:\Users\…\OneDrive - Essence Security\…`): folders are created and the installer argument stays one argv item (Task 2 test `test_data_dir_with_spaces_and_unicode`, Task 15 test `test_installer_command_keeps_spaced_dir_as_one_argument`).
4. No internet or a GitHub rate limit during the update check: Settings shows "Couldn't check for updates" with the reason, nothing crashes, and nothing half-downloaded is ever run (Task 15 tests `test_check_reports_rate_limit_without_raising`, `test_checksum_mismatch_deletes_download`).
5. A harness run starts while a terminal is open, or the process scan meets protected Windows processes: the PTY closes with a notice and the terminal drops to read-only line mode, and protected processes are skipped silently (Task 7 test `test_scan_skips_access_denied_processes`, Task 14 test `test_guard_going_live_closes_pty_and_switches_to_line_mode`).

- Consumes: Task 4 types.
- Produces:
  - `HostKeyStore(path: Path)`, an OpenSSH-format known_hosts file (`[host]:port` when the port is not 22):
    - `get(host, port) -> str | None` (fingerprint)
    - `pin(host, port, info: HostKeyInfo) -> None`
    - `forget(host, port) -> None`

    - Refuses an unpinned host with `HostKeyUnknown`.
    - Maps a key mismatch to `HostKeyChanged`, `PermissionDenied` to `AuthFailed`, and `OSError`/timeouts to `Unreachable`.

  - `GuardReason` (frozen): `kind: Literal["lock_file","process","router_ssid","router_process"], detail: str, since: datetime | None, router: str | None`, with property `text -> str`:
    - `process`: `"dima_night.py started 21:04 (PID 18244)"`
    - `lock_file`: `"Lock file D:\…\voip.lock.own present since 21:04"`
    - `router_ssid`: `"SSID OpenWrtB on air on ap2"`
  - `GuardState` (frozen): `live: bool, reasons: tuple[GuardReason, ...], checked_at: datetime`.
  - `scan_processes(patterns: Sequence[str], lister: Callable[[], Iterable[ProcessInfo]] = psutil_lister) -> list[GuardReason]`:
    - Case-insensitive `fnmatch` against the basename of every cmdline argument.
    - `psutil_lister` skips `AccessDenied`, `NoSuchProcess` and `ZombieProcess`.
  - `BenchGuard(watch: GuardWatchList, lister=psutil_lister, clock=datetime.now)`:
    - `update_watch(watch)`

    - `state() -> GuardState`
    - `require_clear() -> None` raises `GuardLocked(state)`.

Read-only rules:
- **Refuse outright** a command containing any of `;`, `&&`, `||`, `>`, `<`, a backtick, `$(` or a newline.
- **Pipes:** split on `|`; every segment must pass on its own.
- **Programs that are always read-only:** `cat head tail grep wc df free uptime uname date dmesg logread ps ifstatus iwinfo jsonfilter awk sort uniq cut tr md5sum sha256sum which hexdump`.
- **`sed`:** only without `-i`.
- **`find`:** only without `-delete`, `-exec`, `-execdir`.
- **`top`:** only with `-b`.
- **`uci`:** first argument in `show`, `get`, `changes`, `export`.
- **`ubus`:** `list`, `-v list`, or `call` whose method is one of `status info board dump get list getFeatures getBoardJSON getDHCPLeases getHostHints getNetworkDevices getWirelessDevices assoclist freqlist txpowerlist countrylist get_validate get_proto_handlers`.
- **`nft`:** first argument `list`.
- **`tc`:** contains the word `show`, and none of `add`, `del`, `change`, `replace`.
- **`ip`:** subcommand in `addr address link route neigh rule`, and none of `add del set flush change replace`.
- **`iw`:** none of `set del add connect disconnect join leave` and no `scan trigger`.
- **`swconfig`:** contains `show`, `get` or `list`, and not `set`.
- **`apk` / `opkg`:** first argument `list` or `info`.
