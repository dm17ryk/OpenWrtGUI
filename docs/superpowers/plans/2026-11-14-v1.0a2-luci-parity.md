# v1.0a2 LuCI parity II Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** System › Plugins, Mount Points editing and LuCI's iptables page get native screens. Each is proven on a
simulated router whose image has what the bench image lacks. A native LuCI page opens its screen's own tab. Two
fixes carried from the v1.0a1 review land. The Switch/VLAN editor is split off to v1.0a3 (D1).

**Architecture:** Three small services sit next to the existing ones, each with a pure module (parse, rules, uci
ops) and an API module:
- `system/plugins.py` with `system/plugins_service.py`;
- `system/fstab.py` with `system/fstab_service.py`;
- `fw/iptables.py` with `fw/iptables_service.py`.

Every write goes through `ApplyRunner.run_planned` with a `net_plan` preview: the exact lines, the digest, the
audit and Bench Guard, as every screen does. A new simulated router, `ap4` ("AP4 · later image"), proves them. It
has block-mount, iptables, one LuCI plugin and luci-app-sqm. It is not seeded by default, and Playwright runs it in
its own projects on port 8767. `PageView.tab` lets a native page open its screen's tab.

**Tech Stack:** Python 3.13, FastAPI, pydantic 2, pytest (asyncio auto), ruff (line 110), mypy strict, React 19,
TanStack Query, vitest, Playwright e2e on the simulator.

**Spec:** `docs/superpowers/specs/2026-11-03-openwrt-gui-design.md`:
- §8, the LuCI parity table: System › Plugins, Mount points, Status › Firewall;
- §7.6 Firewall, §7.11 System, §7.14 LuCI fallback;
- ROADMAP v1.0: "Native screens for every LuCI page on the bench image (the fallback stays for pages that later
  images bring)".

The v1.0a1 plan's "v1.0a2 outline" and its D11 are the starting point. Dmitry's decisions (relayed 2026-11-13/14):
- **Scope:** Plugins native, Mount Points editing, both iptables views, and Switch/VLAN as "VLAN editor only".
- **VLAN:** the VLAN editor uses the existing 60 s rollback and is proven in the simulator only. The DSA front
  panel, the own-port lock and mirroring stay in 1.x.
- **Base:** build on v1.0a1's design.
- **Simulator first.**
- **README:** the out-of-date README is dealt with (D11).
- **Size:** if it is too big, v1.0a3 takes the VLAN editor.

## Global Constraints

- **Test first:** a change without a test that failed before it is not done (AGENTS.md).
- **Reads:** background reads use `t.run` directly, never `run_audited`. Every read constant passes
  `is_read_only_command` (the convention in `tests/unit/guard/test_readonly*.py`).
- **Writes:**
  - Every write goes through `ApplyRunner.run_planned(rec, make, digest)` with a `net_plan` preview.
  - Every value put into a command matches a `re.fullmatch` rule first and is shell-quoted.
  - During a harness run, Bench Guard refuses the write (`GuardLocked`, 423).
- **No router access.** Nothing in this plan runs on AP2 or any bench router (D8).
- **GitHub:** nothing is pushed and no GitHub object is created without Dmitry's explicit go. Branches are never
  deleted.
- **Public repo:** fixtures hold no real keys, names, neighbour MACs or SSIDs. Plugin ids and UUIDs in fixtures are
  LuCI's published ones or made up.
- **Scripts** run inside `D:\Essence_SC` or `C:\Essence_SC` (SentinelOne).
- **UI:** it keeps working at 375 px and in both themes, and e2e checks for horizontal scroll.
- **Manual headings:** a new or renamed heading means updating `frontend/src/help/topics.ts`. `manual.test.ts`
  checks every topic is a heading.
- **API model changes:** run `uv run python tools/dump_openapi.py && cd frontend && npm run gen:api` after one.
  Fields with defaults become required in the generated TypeScript, so the frontend fixtures carry them (the v1.0a1
  ruling).
- **Style:** ruff line length 110, mypy strict. Small files: the new services do not grow `access_service.py`
  (700+ lines) or `fw/service.py`.

**D4 details: System › Plugins**
- **Reads:**
  - `uci -X show luci_plugins`;
  - `ls -1 /www/luci-static/resources/view/plugins`;
  - `cat …/<id>.js` for each `<32 hex>.js` there.
- **Plugin header.** Each plugin's header (class, type, name, id, title, description) is parsed from the literal
  fields of its `baseclass.extend({...})`. A plugin's own form is JavaScript code, so its own options are shown read
  only, with **Configure in LuCI**. That opens LuCI's Plugins page through the bridge, which still opens native
  pages.
- **Writes** (a plain uci apply of `luci_plugins`, no reload):
  - the global switch, each group switch (`<class>_<type>_enabled`) and each plugin's switch;
  - switching on a plugin that has no section creates it the way LuCI's page does (`<id>=<class>_<type>`, `name`);
  - **Off deletes the option.** LuCI runs a header plugin whatever its `enabled` value, even `'0'` (`run_plugins`
    tests it for truth), so a header plugin with `enabled='0'` shows as on;
  - **Remove** is offered for a section whose plugin file is gone.
- **Login plugins** gate LuCI's web login only. The app's LuCI pages log in over SSH (an rpcd session), so they are
  not affected: the preview warns, nothing is refused.
- **Opening the tab writes nothing.** LuCI's page stages sections when it opens; the app does not.

**D5 details: Mount points editing**
- **What is edited:**
  - the global flags LuCI shows: `anon_swap`, `anon_mount`, `auto_swap`, `auto_mount`, `check_fs`;
  - `mount` sections: `enabled`, one of uuid / label / device, `target`, `fstype`, `options`;
  - `swap` sections: `enabled`, one of uuid / label / device.
- **Devices** come from `ubus call luci getBlockDevices` (LuCI's own read). An entry whose device is absent shows
  "not present".
- **Apply:** a plain uci apply of `fstab`, then `/sbin/block mount`, which is what LuCI's ucitrack runs on an fstab
  change.
- **Unmount:** `umount <target>`. It is not offered where LuCI does not offer it: `/`, `/overlay`, `/rom`, `/tmp…`,
  `/dev…`.
- **Mount attached devices:** `/sbin/block mount`.
- **Generate config:** the app reads what `block detect` prints and replaces fstab's sections with those, as uci
  lines in the preview. LuCI instead writes the file unstaged.
- **For Dmitry:** a mount with target `/` or `/overlay` (extroot), or under `/rom`, `/tmp`, `/dev`, `/proc` or
  `/sys`, is refused. Extroot moves the router's root on the next boot; set it up in LuCI or the terminal.
  (Widened after the final review, Dmitry 2026-11-14 "Widen now, before PR": `/etc`, `/usr`, `/var`, `/www` and
  below are refused too.)
- **Not shown,** as in LuCI: `delay_root` (kept as is), `autofs`, swap `priority`.

**D6 details: Legacy iptables**
- **Both menu paths open it:** `admin/status/iptables` (fw3: nft absent, iptables present) and
  `admin/status/nftables/iptables` (fw4's sub-route). They run the same LuCI view.
- **When it shows:** when the router has `/usr/sbin/iptables`. That includes routers whose Firewall screen shows
  only the "not fw4" note.
- **Reads:** LuCI's exact commands, `iptables --line-numbers -w -nvxL -t <table>` for filter, nat, mangle and raw.
  ip6tables too when `/usr/sbin/ip6tables` exists. Parsed with LuCI's regexes.
- **Writes:**
  - **Reset counters**, `iptables -Z` plus `ip6tables -Z`. Like LuCI, this resets the filter table only, and the
    tab says so.
  - **Restart firewall**, `/etc/init.d/firewall restart`.
- **On AP2 (no iptables):** the sub-route is available by LuCI's depends (it has none). The tab says so instead:
  "No iptables on this router: fw4's rules are under Raw ruleset."

**D7 details: `ap4`**
- **Base:** `base ap2`, `wifi ap2.uci`, `fw ap2.json`, no modem.
- **Its own:**
  - `net ap4.uci`: AP2's at .6, plus `fstab` and `luci_plugins`;
  - `files ap4.json`: AP2's, plus `/sbin/block`, `/usr/sbin/iptables` and `/usr/sbin/ip6tables`;
  - `later ap4.json`, a new `SimLater` that answers:
    - the image's extra menu and ACL files (luci-app-sqm);
    - `getBlockDevices`, `/proc/mounts`, `df`;
    - the iptables listings and their writes;
    - the CSP plugin's JS;
    - `block detect`, `block mount` and `umount`.
- **Seeding:** `"seed": false`, so `ap4` is seeded only when `OPENWRTGUI_SIM_SEED` names it. Tests upsert it; the
  `later-*` Playwright projects set the variable.

**D9 details: e2e**
- After v1.0a2 the bench image has no fallback page left: Plugins and iptables are native. `luci.spec.ts` moves to
  `ap4`'s **Network › SQM QoS**, a later image's page from its menu.
- It runs in two new Playwright projects, `later-desktop-light` and `later-mobile-dark`. They run against a third
  server on 8767, started with `OPENWRTGUI_SIM_SEED=ap4`.
- `later.spec.ts` covers Mount points editing and Legacy iptables on `ap4`.
- Plugins on ap1 goes into `system.spec.ts`, on the main server.

## Review Focus

1. **A plugin file whose fields are not plain literals** (double quotes, `title: _('Content %s').format(x)`, a
   template string, no `type`). The row still shows, with id and name from uci and an empty title, and nothing
   fails. → Task 7 `test_plugin_header_tolerates_other_shapes`.
2. **An fstab mount named only by label or device, whose device is absent now.** It is shown "not present",
   editable, and never dropped on Apply. → Task 9 `test_sections_keep_label_device_and_absent_devices`; Task 10
   `marks a device that is not there`.
3. **A target with a space or a shell character** (`/mnt/usb disk`, `/mnt/$(x)`). It is refused before any command
   is built. → Task 9 `test_values_outside_the_rules_are_refused`.
4. **iptables output with comments.** Takes a rule whose options hold `/* !fw3: comment */`, a chain with references
   instead of a policy, IPv6 addresses with prefixes, and a rule line without options or trailing spaces. Each is
   parsed whole. → Task 11 `test_parse_luci_shapes`, `test_a_rule_without_options_or_trailing_spaces_is_kept`.
5. **A harness run starting between preview and Apply.** It gets 423 and nothing is sent, for all three new writes.
   → Tasks 7, 9, 11 `test_*_refused_during_a_run`.

```python
The menu and ACL reads get the image's extra files; block-mount, iptables and a LuCI plugin answer as on a router
that has them."""

from __future__ import annotations

import json
import re
import shlex
from collections.abc import Mapping
from typing import Any

from openwrtgui.transport.base import CommandResult

_MENU = "for f in /usr/share/luci/menu.d/"
_ACL = "for f in /usr/share/rpcd/acl.d/"
_LISTING = re.compile(r"(ip6?tables) --line-numbers -w -nvxL -t (filter|nat|mangle|raw)")
_RULE_COUNTERS = re.compile(r"^(\d+\s+)\d+(\s+)\d+", re.MULTILINE)
_POLICY_COUNTERS = re.compile(r"\d+ packets, \d+ bytes")
PLUGIN_DIR = "/www/luci-static/resources/view/plugins"


def _ok(command: str, stdout: str = "") -> CommandResult:
    return CommandResult(command, stdout, "", 0)


def _fail(command: str, stderr: str, status: int = 1) -> CommandResult:
    return CommandResult(command, "", stderr, status)


def _files(spec: Mapping[str, Any]) -> str:
    return "".join(f"=== {path}\n{json.dumps(body, indent='\t')}\n" for path, body in spec.items())


class SimLater:
    def __init__(self, spec: Mapping[str, Any], base: Mapping[str, CommandResult]) -> None:
        self._spec = spec
        self._base = base
        self._mounts = str(spec["mounts"])
        self._zeroed: set[str] = set()

    def _extended(self, command: str, extra: Mapping[str, Any]) -> CommandResult:
        recorded = self._base[command]
        return CommandResult(command, recorded.stdout + _files(extra), recorded.stderr, recorded.exit_status)

    def _listing(self, command: str, program: str, table: str) -> CommandResult:
        text = str(self._spec[program][table])
        if program in self._zeroed and table == "filter":  # -Z without -t: the filter table only
            text = _POLICY_COUNTERS.sub("0 packets, 0 bytes", _RULE_COUNTERS.sub(r"\g<1>0\g<2>0", text))
        return _ok(command, text)

    def answer(self, command: str) -> CommandResult | None:
        c = command.strip()
        if c.startswith(_MENU) and c in self._base:
            return self._extended(c, self._spec["menu"])
        if c.startswith(_ACL) and c in self._base:
            return self._extended(c, self._spec["acl"])
        if c == "ubus call luci getBlockDevices":
            return _ok(c, json.dumps(self._spec["block_devices"], indent="\t") + "\n")
        if c == "cat /proc/mounts":
            return _ok(c, self._mounts)
        if c == "df -k":
            return _ok(c, str(self._spec["df"]))
        if c == "block detect":
            return _ok(c, str(self._spec["detect"]))
        if c == "/sbin/block mount":
            return _ok(c)
        if c.startswith("umount "):
            target = shlex.split(c)[1]
            lines = self._mounts.splitlines(keepends=True)
            kept = [line for line in lines if line.split()[1:2] != [target]]
            if len(kept) == len(lines):
                return _fail(c, f"umount: can't unmount {target}: Invalid argument\n")
            self._mounts = "".join(kept)
            return _ok(c)
        if m := _LISTING.fullmatch(c):
            return self._listing(c, m.group(1), m.group(2))
        if c in ("iptables -Z", "ip6tables -Z"):
            self._zeroed.add(c.split()[0])
            return _ok(c)
        if c == "/etc/init.d/firewall restart":
            return _ok(c)
        if c == f"ls -1 {PLUGIN_DIR}":
            return _ok(c, "".join(f"{name}\n" for name in sorted(self._spec["plugins"])))
        if c.startswith(f"cat {PLUGIN_DIR}/"):
            name = c.removeprefix(f"cat {PLUGIN_DIR}/")
            text = self._spec["plugins"].get(name)
            if text is None:
                return _fail(c, f"cat: can't open '{PLUGIN_DIR}/{name}': No such file or directory\n")
            return _ok(c, str(text))
        return None
```

```python
"""System › Plugins (v1.0a2 D4): LuCI's plugin switches in /etc/config/luci_plugins.

A plugin is a JS file in PLUGIN_DIR named by its 32-hex id; its `baseclass.extend({...})` names its class and type
(http/headers, auth/login, ...). luci_plugins holds `global` (`enabled`, `<class>_<type>_enabled`) and one section
per plugin, named by its id, of type `<class>_<type>`. A plugin's own form is JS code: its options are shown, and
edited in LuCI.
"""

from __future__ import annotations

import re
from collections.abc import Mapping, Sequence

from pydantic import BaseModel, ConfigDict

from openwrtgui.system.commands import PLUGIN_DIR
from openwrtgui.uci import UciOp

PLUGIN_ID = re.compile(r"[0-9a-f]{32}")
PLUGIN_FILE = re.compile(r"([0-9a-f]{32})\.js")
_WORD = re.compile(r"[a-z][a-z0-9]{0,31}")  # a plugin class or type
# `key: 'literal'` or `key: _('literal')`, single or double quotes; the first of each key wins
_FIELD = re.compile(r"""\b(class|type|name|id|title|description)\s*:\s*(?:_\(\s*)?(['"])((?:(?!\2).){0,300})\2""")
LOGIN_WARNING = (
    "A login plugin adds a step to LuCI's web login on this router. The LuCI pages in this app log in over SSH "
    "and are not affected."
)


class PluginHeader(BaseModel):
    model_config = ConfigDict(frozen=True)

    id: str
    class_name: str
    type_name: str
    name: str
    title: str
    description: str


class PluginRow(BaseModel):
    model_config = ConfigDict(frozen=True)

    id: str
    group: str  # `<class>_<type>`: the section type and the global switch's prefix
    name: str
    title: str
    description: str
    installed: bool  # its JS file is there
    configured: bool  # it has a section
    enabled: bool  # LuCI runs it (header plugins: any `enabled` value; login plugins: '1')
    options: dict[str, str]  # its own options, shown; edited in LuCI


class PluginGroup(BaseModel):
    model_config = ConfigDict(frozen=True)

    key: str
    enabled: bool


class PluginState(BaseModel):
    model_config = ConfigDict(frozen=True)

    enabled: bool
    global_section: bool
    groups: list[PluginGroup]
    plugins: list[PluginRow]
    missing: tuple[str, ...] = ()  # "luci_plugins config": the router has no such config


class PluginChange(BaseModel):
    model_config = ConfigDict(frozen=True)

    enabled: bool | None = None  # the global switch; None leaves it
    groups: dict[str, bool] = {}
    plugins: dict[str, bool] = {}
    remove: list[str] = []  # sections whose plugin file is gone


def read_plugin_command(file_id: str) -> str:
    if not PLUGIN_ID.fullmatch(file_id):
        raise ValueError(f"{file_id!r} is not a plugin id")
    return f"cat {PLUGIN_DIR}/{file_id}.js"


def parse_header(file_id: str, text: str) -> PluginHeader | None:
    """The literal fields of a plugin's declaration. None when it names no class or type (no group)."""
    found: dict[str, str] = {}
    for m in _FIELD.finditer(text):
        found.setdefault(m.group(1), m.group(3))
    cls, typ = found.get("class", ""), found.get("type", "")
    if not (_WORD.fullmatch(cls) and _WORD.fullmatch(typ)):
        return None
    return PluginHeader(
        id=file_id,
        class_name=cls,
        type_name=typ,
        name=found.get("name", file_id),
        title=found.get("title", ""),
        description=found.get("description", ""),
    )


def _runs(group: str, value: str | None) -> bool:
    # luciplugins.uc: a login plugin loads only with enabled == "1"; header plugins run on any value (truthy)
    return value == "1" if group.startswith("auth_") else bool(value)


def plugin_state(uci: Mapping[str, str], headers: Sequence[PluginHeader]) -> PluginState:
    by_id = {h.id: h for h in headers}
    sections = {k.split(".", 1)[1]: v for k, v in uci.items() if k.count(".") == 1}
    rows: list[PluginRow] = []
    for pid in sorted(set(by_id) | {n for n in sections if PLUGIN_ID.fullmatch(n)}):
        h = by_id.get(pid)
        group = f"{h.class_name}_{h.type_name}" if h else sections[pid]
        prefix = f"luci_plugins.{pid}."
        opts = {k.removeprefix(prefix): v for k, v in uci.items() if k.startswith(prefix)}
        rows.append(
            PluginRow(
                id=pid,
                group=group,
                name=opts.get("name") or (h.name if h else pid),
                title=h.title if h else "",
                description=h.description if h else "",
                installed=h is not None,
                configured=pid in sections,
                enabled=_runs(group, opts.get("enabled")),
                options={k: v for k, v in opts.items() if k not in ("name", "enabled")},
            )
        )
    groups = sorted({r.group for r in rows})
    return PluginState(
        enabled=uci.get("luci_plugins.global.enabled") == "1",
        global_section="luci_plugins.global" in uci,
        groups=[PluginGroup(key=g, enabled=uci.get(f"luci_plugins.global.{g}_enabled") == "1") for g in groups],
        plugins=rows,
    )


def _switch(path: str, on: bool) -> UciOp:
    # Off deletes: a header plugin with enabled='0' would still run (D4)
    return UciOp("set", path, "1") if on else UciOp("delete", path)


def plugin_ops(state: PluginState, change: PluginChange) -> list[UciOp]:
    rows = {r.id: r for r in state.plugins}
    groups = {g.key for g in state.groups}
    ops: list[UciOp] = []
    if (change.enabled or change.groups) and not state.global_section:
        ops.append(UciOp("set", "luci_plugins.global", "global"))
    if change.enabled is not None:
        ops.append(_switch("luci_plugins.global.enabled", change.enabled))
    for key, on in change.groups.items():
        if key not in groups:
            raise ValueError(f"No plugin group {key} on this router")
        ops.append(_switch(f"luci_plugins.global.{key}_enabled", on))
    for pid, on in change.plugins.items():
        row = rows.get(pid)
        if row is None or not row.installed:
            raise ValueError(f"No installed plugin {pid} on this router")
        if on and not row.configured:
            ops += [UciOp("set", f"luci_plugins.{pid}", row.group), UciOp("set", f"luci_plugins.{pid}.name", row.name)]
        ops.append(_switch(f"luci_plugins.{pid}.enabled", on))
    for pid in change.remove:
        row = rows.get(pid)
        if row is None or row.installed or not row.configured:
            raise ValueError(f"Only a plugin whose file is gone can be removed ({pid})")
        ops.append(UciOp("delete", f"luci_plugins.{pid}"))
    return ops
```

Group keys and plugin ids reach a uci path unquoted. They come only from the router's own section types (libuci
allows `[A-Za-z0-9_]`) and from `_WORD` and `PLUGIN_ID`, and every change key is checked against them first.

```python
"""System › Plugins (v1.0a2 D4): read the plugins and their switches; apply a change with the plain uci apply."""

from __future__ import annotations

from openwrtgui.net.apply import ApplyRunner, NetApplyResult, NetCheck, NetPlan, Planned, net_plan, saved_check
from openwrtgui.store.routers import RouterRecord, RouterStore
from openwrtgui.system import commands as s
from openwrtgui.system.plugins import (
    LOGIN_WARNING,
    PLUGIN_FILE,
    PluginChange,
    PluginHeader,
    PluginState,
    parse_header,
    plugin_ops,
    plugin_state,
    read_plugin_command,
)
from openwrtgui.transport.base import Transport
from openwrtgui.transport.pool import ConnectionPool
from openwrtgui.uci import parse_uci_show

SCREEN = "System"


class PluginsService:
    def __init__(self, *, pool: ConnectionPool, routers: RouterStore, runner: ApplyRunner) -> None:
        self._pool = pool
        self._routers = routers
        self._runner = runner

    def _record(self, router_id: str) -> RouterRecord:
        rec = self._routers.get(router_id)
        if rec is None:
            raise ValueError(f"Unknown router {router_id}")
        return rec

    async def _read(self, t: Transport) -> tuple[PluginState, dict[str, str]]:
        shown = await t.run(s.UCI_PLUGINS)
        uci = parse_uci_show(shown.stdout) if shown.ok else {}
        headers: list[PluginHeader] = []
        listed = await t.run(s.LIST_PLUGINS)  # no such folder: no plugins installed
        if listed.ok:
            for name in listed.stdout.split():
                if m := PLUGIN_FILE.fullmatch(name):
                    text = await t.run(read_plugin_command(m.group(1)))
                    header = parse_header(m.group(1), text.stdout) if text.ok else None
                    if header is not None:
                        headers.append(header)
        state = plugin_state(uci, headers)
        if not shown.ok:
            state = state.model_copy(update={"missing": ("luci_plugins config",)})
        return state, uci

    async def state(self, router_id: str) -> PluginState:
        rec = self._record(router_id)
        return (await self._read(await self._pool.get(rec)))[0]

    def _plan(self, rec: RouterRecord, state: PluginState, current: dict[str, str], change: PluginChange) -> NetPlan:
        if state.missing:
            raise ValueError(f"{rec.name} has no /etc/config/luci_plugins: LuCI's Plugins page is not on this image")
        login_on = any(on and k.startswith("auth_") for k, on in change.groups.items()) or any(
            on and r.group.startswith("auth_") for r in state.plugins if change.plugins.get(r.id)
        )
        return net_plan(
            router_id=rec.id,
            screen=SCREEN,
            config="luci_plugins",
            ops=plugin_ops(state, change),
            current=current,
            warnings=[LOGIN_WARNING] if login_on else [],
        )

    async def plan(self, router_id: str, change: PluginChange) -> NetPlan:
        rec = self._record(router_id)
        state, current = await self._read(await self._pool.get(rec))
        return self._plan(rec, state, current, change)

    async def apply(self, router_id: str, change: PluginChange, digest: str | None) -> NetApplyResult:
        rec = self._record(router_id)

        async def make(t: Transport) -> Planned:
            state, current = await self._read(t)
            plan = self._plan(rec, state, current, change)

            async def verify(t2: Transport) -> list[NetCheck]:
                return [await saved_check(t2, s.UCI_PLUGINS, plan.ops, current)]

            return Planned(plan, verify)

        return await self._runner.run_planned(rec, make, digest)
```

```python
"""Mount points with block-mount (v1.0a2 D5): /etc/config/fstab as LuCI's Mount Points page edits it.

`global` holds LuCI's five flags (and delay_root, kept); `mount` and `swap` sections name their device by UUID, else
label, else device, as fstools reads them. Every value matches a rule before it reaches a uci line.
"""

from __future__ import annotations

import json
import re
from collections.abc import Mapping, Sequence
from typing import Any, Literal

from pydantic import BaseModel, ConfigDict

from openwrtgui.uci import UciOp

MOUNT_PATH = re.compile(r"/[A-Za-z0-9._/-]{0,254}")
UUID = re.compile(r"[0-9A-Fa-f][0-9A-Fa-f-]{3,63}")
LABEL = re.compile(r"[A-Za-z0-9 ._-]{1,32}")  # quoted in every line it goes into
DEVICE = re.compile(r"/dev/[A-Za-z0-9._/-]{1,64}")
FSTYPE = re.compile(r"[a-z0-9]{1,16}")
OPTIONS = re.compile(r"[A-Za-z0-9,=._:/+-]{1,255}")
PROTECTED = re.compile(r"/(?:overlay|rom|tmp(?:/.+)?|dev(?:/.+)?|)")  # LuCI offers no Unmount for these
# D5: extroot (/, /overlay) and the router's own file systems are no mount targets here
REFUSED_TARGET = re.compile(r"/(?:|overlay|rom|(?:tmp|dev|proc|sys)(?:/.*)?)")
FLAGS = ("anon_swap", "anon_mount", "auto_swap", "auto_mount", "check_fs")
_CONFIG = re.compile(r"config\s+'?(\w+)'?")
_OPTION = re.compile(r"option\s+'?(\w+)'?\s+'([^']*)'")


class FstabGlobal(BaseModel):
    model_config = ConfigDict(frozen=True)

    anon_swap: bool = False
    anon_mount: bool = False
    auto_swap: bool = True
    auto_mount: bool = True
    check_fs: bool = False
    delay_root: int | None = None  # not shown (LuCI shows it neither); kept, and written by Generate


class FstabEntry(BaseModel):
    model_config = ConfigDict(frozen=True)

    section: str | None = None  # None: a new section
    kind: Literal["mount", "swap"]
    enabled: bool = True
    uuid: str | None = None
    label: str | None = None
    device: str | None = None
    target: str | None = None  # mounts only
    fstype: str | None = None
    options: str | None = None


class BlockDevice(BaseModel):
    model_config = ConfigDict(frozen=True)

    dev: str
    uuid: str | None = None
    label: str | None = None
    type: str | None = None
    size: int | None = None
    mount: str | None = None


class FstabState(BaseModel):
    model_config = ConfigDict(frozen=True)

    block: bool  # block-mount is installed: without it LuCI has no Mount Points page
    settings: FstabGlobal = FstabGlobal()
    global_section: str | None = None
    entries: list[FstabEntry] = []
    devices: list[BlockDevice] = []
    missing: tuple[str, ...] = ()  # "fstab config", "block devices": what could not be read


class FstabChange(BaseModel):
    model_config = ConfigDict(frozen=True)

    settings: FstabGlobal | None = None
    entries: list[FstabEntry] | None = None  # the whole list as edited: a section left out is deleted


def _flags(get: Any, defaults: FstabGlobal) -> dict[str, bool]:
    return {f: (getattr(defaults, f) if get(f) is None else get(f) == "1") for f in FLAGS}


def _delay(value: str | None) -> int | None:
    return int(value) if value is not None and value.isdigit() else None


def _entry(kind: str, get: Any, section: str | None) -> FstabEntry:
    mount = kind == "mount"
    return FstabEntry(
        section=section,
        kind="mount" if mount else "swap",
        enabled=(get("enabled") or "1") == "1",
        uuid=get("uuid"),
        label=get("label"),
        device=get("device"),
        target=get("target") if mount else None,
        fstype=get("fstype") if mount else None,
        options=get("options") if mount else None,
    )


def parse_fstab(uci: Mapping[str, str]) -> tuple[str | None, FstabGlobal, list[FstabEntry]]:
    sections = [(k.split(".", 1)[1], v) for k, v in uci.items() if k.startswith("fstab.") and k.count(".") == 1]
    name = next((n for n, kind in sections if kind == "global"), None)
    settings = FstabGlobal()
    if name is not None:
        p = f"fstab.{name}."
        settings = FstabGlobal(**_flags(lambda o: uci.get(p + o), settings), delay_root=_delay(uci.get(p + "delay_root")))
    entries = [
        _entry(kind, lambda o, n=n: uci.get(f"fstab.{n}.{o}"), n) for n, kind in sections if kind in ("mount", "swap")
    ]
    return name, settings, entries


def parse_block_devices(text: str) -> list[BlockDevice]:
    """`ubus call luci getBlockDevices`: {dev: {dev, uuid, label, type, size, mount}}; anything else: none."""
    try:
        data = json.loads(text)
    except ValueError:
        return []
    if not isinstance(data, dict):
        return []
    devices = []
    for info in data.values():
        if isinstance(info, dict) and isinstance(info.get("dev"), str):
            size = info.get("size")
            devices.append(
                BlockDevice(
                    dev=info["dev"],
                    uuid=info.get("uuid") if isinstance(info.get("uuid"), str) else None,
                    label=info.get("label") if isinstance(info.get("label"), str) else None,
                    type=info.get("type") if isinstance(info.get("type"), str) else None,
                    size=size if isinstance(size, int) else None,
                    mount=info.get("mount") if isinstance(info.get("mount"), str) else None,
                )
            )
    return sorted(devices, key=lambda d: d.dev)


def present(entry: FstabEntry, devices: Sequence[BlockDevice]) -> BlockDevice | None:
    """The device an entry names now, matched as LuCI does: UUID (any case), then label, then device."""
    for d in devices:
        if entry.uuid and d.uuid and entry.uuid.lower() == d.uuid.lower():
            return d
    for d in devices:
        if not entry.uuid and entry.label and d.label == entry.label:
            return d
    for d in devices:
        if not entry.uuid and not entry.label and entry.device and d.dev == entry.device:
            return d
    return None


def parse_detect(text: str) -> tuple[FstabGlobal, list[FstabEntry]]:
    """What `block detect` prints (an fstab in uci file syntax)."""
    blocks: list[tuple[str, dict[str, str]]] = []
    for line in text.splitlines():
        s = line.strip()
        if m := _CONFIG.fullmatch(s):
            blocks.append((m.group(1), {}))
        elif (m := _OPTION.fullmatch(s)) and blocks:
            blocks[-1][1][m.group(1)] = m.group(2)
    settings = FstabGlobal()
    entries: list[FstabEntry] = []
    for kind, opts in blocks:
        if kind == "global":
            settings = FstabGlobal(**_flags(opts.get, settings), delay_root=_delay(opts.get("delay_root")))
        elif kind in ("mount", "swap"):
            entries.append(_entry(kind, opts.get, None))
    return settings, entries


def _checked(rule: re.Pattern[str], value: str, what: str) -> str:
    if not rule.fullmatch(value):
        raise ValueError(f"{value!r} is not {what}")
    return value


def check_entry(e: FstabEntry) -> None:
    if e.uuid:
        _checked(UUID, e.uuid, "a UUID")
    elif e.label:
        _checked(LABEL, e.label, "a label (letters, digits, spaces, . _ -)")
    elif e.device:
        _checked(DEVICE, e.device, "a device under /dev")
    else:
        raise ValueError(f"A {e.kind} names its device by UUID, label or device")
    if e.kind != "mount":
        return
    if not e.target:
        raise ValueError("A mount needs a mount point")
    _checked(MOUNT_PATH, e.target, "a mount point (an absolute path of letters, digits, . _ - /)")
    if REFUSED_TARGET.fullmatch(e.target.rstrip("/") or "/"):
        raise ValueError(
            f"{e.target} is the router's own file system: set up extroot or system mounts in LuCI or the terminal"
        )
    if e.fstype:
        _checked(FSTYPE, e.fstype, "a file system type")
    if e.options:
        _checked(OPTIONS, e.options, "mount options (letters, digits and , = . _ : / + -)")


def _option(path: str, name: str, value: str | None, new: bool) -> list[UciOp]:
    if value:
        return [UciOp("set", f"{path}.{name}", value)]
    return [] if new else [UciOp("delete", f"{path}.{name}")]  # a new section has nothing to delete


def _entry_ops(path: str, e: FstabEntry, new: bool) -> list[UciOp]:
    ops = [UciOp("set", f"{path}.enabled", "1" if e.enabled else "0")]
    # one name for the device, as LuCI writes it: UUID, else label, else device
    ops += _option(path, "uuid", e.uuid, new)
    ops += _option(path, "label", None if e.uuid else e.label, new)
    ops += _option(path, "device", None if (e.uuid or e.label) else e.device, new)
    if e.kind == "mount":
        for name in ("target", "fstype", "options"):
            ops += _option(path, name, getattr(e, name), new)
    return ops


def fstab_ops(global_section: str | None, current: Sequence[FstabEntry], change: FstabChange) -> list[UciOp]:
    ops: list[UciOp] = []
    if change.settings is not None:
        path = f"fstab.{global_section}" if global_section else "fstab.$g"
        if global_section is None:
            ops.append(UciOp("add", path, "global"))
        ops += [UciOp("set", f"{path}.{f}", "1" if getattr(change.settings, f) else "0") for f in FLAGS]
        if change.settings.delay_root is not None:
            ops.append(UciOp("set", f"{path}.delay_root", str(change.settings.delay_root)))
    if change.entries is not None:
        kinds = {e.section: e.kind for e in current if e.section}
        kept: set[str] = set()
        for i, e in enumerate(change.entries, 1):
            check_entry(e)
            if e.section is None:
                path = f"fstab.$m{i}"
                ops += [UciOp("add", path, e.kind), *_entry_ops(path, e, new=True)]
                continue
            if kinds.get(e.section) != e.kind:
                raise ValueError(f"No {e.kind} section {e.section} on this router")
            kept.add(e.section)
            ops += _entry_ops(f"fstab.{e.section}", e, new=False)
        ops += [UciOp("delete", f"fstab.{s}") for s in sorted(set(kinds) - kept)]
    return ops


def generate_ops(global_section: str | None, current: Sequence[FstabEntry], detected: str) -> list[UciOp]:
    """LuCI's Generate Config (D5): every section replaced with what `block detect` printed."""
    settings, entries = parse_detect(detected)
    if not detected.strip():
        raise ValueError("block detect printed nothing")
    old = [s for s in [global_section, *(e.section for e in current)] if s]
    return [UciOp("delete", f"fstab.{s}") for s in old] + fstab_ops(
        None, [], FstabChange(settings=settings, entries=entries)
    )
```

names (`kinds`). Every value is quoted by `render_uci`.

```python
"""Mount points with block-mount (v1.0a2 D5): read fstab and the block devices; apply edits, Generate Config,
Unmount and Mount attached devices through the plain apply."""

from __future__ import annotations

from collections.abc import Awaitable, Callable, Sequence

from openwrtgui.net.apply import ApplyRunner, NetApplyResult, NetCheck, NetPlan, Planned, net_plan, saved_check
from openwrtgui.store.routers import RouterRecord, RouterStore
from openwrtgui.system import commands as s
from openwrtgui.system.fstab import (
    MOUNT_PATH,
    PROTECTED,
    FstabChange,
    FstabState,
    fstab_ops,
    generate_ops,
    parse_block_devices,
    parse_fstab,
    present,
)
from openwrtgui.system.mounts import parse_mounts
from openwrtgui.transport.base import Transport
from openwrtgui.transport.pool import ConnectionPool
from openwrtgui.uci import UciOp, parse_uci_show, shell_quote

SCREEN = "System"
GENERATE_WARNING = "Replaces every fstab section with what block detect finds now; the mounts it finds start disabled."
Build = Callable[[Transport], Awaitable[tuple[NetPlan, dict[str, str]]]]


class FstabService:
    def __init__(self, *, pool: ConnectionPool, routers: RouterStore, runner: ApplyRunner) -> None:
        self._pool = pool
        self._routers = routers
        self._runner = runner

    def _record(self, router_id: str) -> RouterRecord:
        rec = self._routers.get(router_id)
        if rec is None:
            raise ValueError(f"Unknown router {router_id}")
        return rec

    async def _read(self, t: Transport) -> tuple[FstabState, dict[str, str]]:
        if (await t.run(s.HAS_BLOCK)).exit_status != 0:
            return FstabState(block=False), {}
        shown = await t.run(s.UCI_FSTAB)
        uci = parse_uci_show(shown.stdout) if shown.ok else {}
        name, settings, entries = parse_fstab(uci)
        devices = await t.run(s.BLOCK_DEVICES)
        missing = (() if shown.ok else ("fstab config",)) + (() if devices.ok else ("block devices",))
        state = FstabState(
            block=True,
            settings=settings,
            global_section=name,
            entries=entries,
            devices=parse_block_devices(devices.stdout) if devices.ok else [],
            missing=missing,
        )
        return state, uci

    async def state(self, router_id: str) -> FstabState:
        return (await self._read(await self._pool.get(self._record(router_id))))[0]

    def _usable(self, rec: RouterRecord, state: FstabState) -> None:
        if not state.block:
            raise ValueError(f"{rec.name} has no block-mount: LuCI's Mount Points page is not on this image")
        if "fstab config" in state.missing:
            raise ValueError(f"{rec.name} has no /etc/config/fstab: create it in the terminal with `block detect`")

    def _uci_plan(
        self, rec: RouterRecord, current: dict[str, str], ops: Sequence[UciOp], *, mount: bool, warnings: Sequence[str] = ()
    ) -> NetPlan:
        return net_plan(
            router_id=rec.id,
            screen=SCREEN,
            config="fstab",
            ops=ops,
            current=current,
            reloads=[s.BLOCK_MOUNT] if mount else [],
            warnings=warnings,
        )

    async def _change_plan(self, rec: RouterRecord, t: Transport, change: FstabChange) -> tuple[NetPlan, dict[str, str]]:
        state, current = await self._read(t)
        self._usable(rec, state)
        ops = fstab_ops(state.global_section, state.entries, change)
        return self._uci_plan(rec, current, ops, mount=True), current

    async def _generate_plan(self, rec: RouterRecord, t: Transport) -> tuple[NetPlan, dict[str, str]]:
        state, current = await self._read(t)
        self._usable(rec, state)
        detected = await t.run(s.BLOCK_DETECT)
        if not detected.ok:
            raise ValueError(f"block detect failed on {rec.name}: {(detected.stderr or detected.stdout).strip()}")
        ops = generate_ops(state.global_section, state.entries, detected.stdout)
        return self._uci_plan(rec, current, ops, mount=False, warnings=[GENERATE_WARNING]), current

    async def plan(self, router_id: str, change: FstabChange) -> NetPlan:
        rec = self._record(router_id)
        return (await self._change_plan(rec, await self._pool.get(rec), change))[0]

    async def plan_generate(self, router_id: str) -> NetPlan:
        rec = self._record(router_id)
        return (await self._generate_plan(rec, await self._pool.get(rec)))[0]

    async def _apply_uci(self, rec: RouterRecord, digest: str | None, build: Build) -> NetApplyResult:
        async def make(t: Transport) -> Planned:
            plan, current = await build(t)

            async def verify(t2: Transport) -> list[NetCheck]:
                return [await saved_check(t2, s.UCI_FSTAB, plan.ops, current)]

            return Planned(plan, verify)

        return await self._runner.run_planned(rec, make, digest)

    async def apply(self, router_id: str, change: FstabChange, digest: str | None) -> NetApplyResult:
        rec = self._record(router_id)
        return await self._apply_uci(rec, digest, lambda t: self._change_plan(rec, t, change))

    async def apply_generate(self, router_id: str, digest: str | None) -> NetApplyResult:
        rec = self._record(router_id)
        return await self._apply_uci(rec, digest, lambda t: self._generate_plan(rec, t))

    # ---------------------------------------------------------------- Unmount, Mount attached devices
    async def _mounted(self, t: Transport) -> set[str]:
        return {m.target for m in parse_mounts((await t.run(s.MOUNTS)).stdout)}

    async def _unmount_plan(self, rec: RouterRecord, t: Transport, target: str) -> NetPlan:
        if not MOUNT_PATH.fullmatch(target):
            raise ValueError(f"{target!r} is not a mount point")
        if PROTECTED.fullmatch(target):
            raise ValueError(f"{target} is not unmounted here (LuCI offers no Unmount for it)")
        self._usable(rec, (await self._read(t))[0])
        if target not in await self._mounted(t):
            raise ValueError(f"Nothing is mounted at {target}")
        return net_plan(
            router_id=rec.id, screen=SCREEN, config=None, ops=[], current={}, commands=[f"umount {shell_quote(target)}"]
        )

    async def plan_unmount(self, router_id: str, target: str) -> NetPlan:
        rec = self._record(router_id)
        return await self._unmount_plan(rec, await self._pool.get(rec), target)

    async def apply_unmount(self, router_id: str, target: str, digest: str | None) -> NetApplyResult:
        rec = self._record(router_id)

        async def make(t: Transport) -> Planned:
            plan = await self._unmount_plan(rec, t, target)

            async def verify(t2: Transport) -> list[NetCheck]:
                gone = target not in await self._mounted(t2)
                return [NetCheck(f"{target} unmounted", gone, "no longer in /proc/mounts" if gone else "still mounted")]

            return Planned(plan, verify)

        return await self._runner.run_planned(rec, make, digest)

    async def _mount_plan(self, rec: RouterRecord, t: Transport) -> tuple[NetPlan, FstabState]:
        state = (await self._read(t))[0]
        self._usable(rec, state)
        return net_plan(router_id=rec.id, screen=SCREEN, config=None, ops=[], current={}, commands=[s.BLOCK_MOUNT]), state

    async def plan_mount(self, router_id: str) -> NetPlan:
        rec = self._record(router_id)
        return (await self._mount_plan(rec, await self._pool.get(rec)))[0]

    async def apply_mount(self, router_id: str, digest: str | None) -> NetApplyResult:
        rec = self._record(router_id)

        async def make(t: Transport) -> Planned:
            plan, state = await self._mount_plan(rec, t)
            wanted = [e for e in state.entries if e.kind == "mount" and e.enabled and present(e, state.devices) and e.target]

            async def verify(t2: Transport) -> list[NetCheck]:
                mounted = await self._mounted(t2)
                checks = [NetCheck(f"{e.target} mounted", e.target in mounted, "") for e in wanted]
                return checks or [NetCheck("block mount", True, "no enabled mount has its device here")]

            return Planned(plan, verify)

        return await self._runner.run_planned(rec, make, digest)
```

```tsx
import { useState } from 'react'
import type { BlockDevice, FstabEntry, FstabGlobal, FstabState } from '../../api/types'
import { usePlanApply } from '../../components/usePlanApply'
import { HELP } from '../../help/topics'
import { NetChange } from '../net/NetChange'

type Props = { routerId: string; short: string; state: FstabState }

const FLAGS: [keyof FstabGlobal, string][] = [
  ['auto_mount', 'Mount automatically (auto_mount)'],
  ['auto_swap', 'Swap automatically (auto_swap)'],
  ['anon_mount', 'Mount devices fstab does not list (anon_mount)'],
  ['anon_swap', 'Swap on devices fstab does not list (anon_swap)'],
  ['check_fs', 'Check file systems before mounting (check_fs)'],
]

const blank = (kind: 'mount' | 'swap'): FstabEntry => ({
  section: null,
  kind,
  enabled: true,
  uuid: null,
  label: null,
  device: null,
  target: kind === 'mount' ? '/mnt/' : null,
  fstype: null,
  options: null,
})

function presentDevice(e: FstabEntry, devices: BlockDevice[]): BlockDevice | undefined {
  return (
    devices.find((d) => e.uuid && d.uuid && d.uuid.toLowerCase() === e.uuid.toLowerCase()) ??
    devices.find((d) => !e.uuid && e.label && d.label === e.label) ??
    devices.find((d) => !e.uuid && !e.label && e.device && d.dev === e.device)
  )
}

const describe = (d: BlockDevice): string => [d.dev, d.label, d.type].filter(Boolean).join(' · ')

/** LuCI's Mount Points page with block-mount (v1.0a2 D5): fstab's settings and entries, Generate, Mount all. */
export function FstabCard({ routerId, short, state }: Props) {
  const client = useQueryClient()
  const [settings, setSettings] = useState<FstabGlobal | null>(null)
  const [entries, setEntries] = useState<FstabEntry[] | null>(null)
  const [action, setAction] = useState<'generate' | 'mount' | null>(null)
  const done = (): void => {
    setSettings(null)
    setEntries(null)
    setAction(null)
    void client.invalidateQueries({ queryKey: ['system-fstab', routerId] })
    void client.invalidateQueries({ queryKey: ['system-mounts', routerId] })
  }
  const base = `/api/routers/${routerId}/system/fstab`
  const body = settings || entries ? { settings, entries } : null
  const edit = usePlanApply(base, body, done)
  const run = usePlanApply(action ? `${base}/${action}` : base, action ? {} : null, done)
  const shownSettings = settings ?? state.settings
  const rows = entries ?? state.entries
  const setRow = (i: number, patch: Partial<FstabEntry>): void => setEntries(rows.map((e, j) => (j === i ? { ...e, ...patch } : e)))
  const pick = (i: number, value: string): void => {
    const d = state.devices.find((x) => (x.uuid ?? x.dev) === value)
    if (d) setRow(i, d.uuid ? { uuid: d.uuid, label: null, device: null } : { uuid: null, label: null, device: d.dev })
  }
  return (
    <div className="stack">
      <h3>fstab</h3>
      {state.missing.length > 0 && <div className="note w">Could not read: {state.missing.join(', ')}.</div>}
      <fieldset className="stack">
        <legend>Settings</legend>
        {FLAGS.map(([key, label]) => (
          <label key={key} className="row">
            <input type="checkbox" checked={Boolean(shownSettings[key])} onChange={(e) => setSettings({ ...shownSettings, [key]: e.target.checked })} />
            {label}
          </label>
        ))}
      </fieldset>
      <div className="scroll-x">
        <table className="tbl" aria-label="fstab entries">
          <thead>
            <tr>
              <th>Enabled</th>
              <th>Kind</th>
              <th>Device</th>
              <th>Mount point</th>
              <th>Type</th>
              <th>Options</th>
              <th />
            </tr>
          </thead>
          <tbody>
            {rows.map((e, i) => {
              const d = presentDevice(e, state.devices)
              const named = e.uuid ?? e.label ?? e.device ?? ''
              return (
                <tr key={e.section ?? `new-${i}`}>
                  <td>
                    <input type="checkbox" aria-label="Enabled" checked={e.enabled} onChange={(x) => setRow(i, { enabled: x.target.checked })} />
                  </td>
                  <td>{e.kind}</td>
                  <td>
                    <select aria-label="Device" value={d ? (d.uuid ?? d.dev) : named} onChange={(x) => pick(i, x.target.value)}>
                      {!d && <option value={named}>{named || 'choose a device'}</option>}
                      {state.devices.map((x) => (
                        <option key={x.dev} value={x.uuid ?? x.dev}>

                        </option>
                      ))}
                    </select>
                    {!d && named && <div className="muted">not present</div>}
                  </td>
                  <td>{e.kind === 'mount' && <input aria-label="Mount point" className="mono" value={e.target ?? ''} onChange={(x) => setRow(i, { target: x.target.value })} />}</td>
                  <td>{e.kind === 'mount' && <input aria-label="Type" className="mono" placeholder="auto" value={e.fstype ?? ''} onChange={(x) => setRow(i, { fstype: x.target.value || null })} />}</td>
                  <td>{e.kind === 'mount' && <input aria-label="Options" className="mono" placeholder="defaults" value={e.options ?? ''} onChange={(x) => setRow(i, { options: x.target.value || null })} />}</td>
                  <td>
                    <button type="button" className="btn" onClick={() => setEntries(rows.filter((_, j) => j !== i))}>
                      Remove
                    </button>
                  </td>
                </tr>
              )
            })}
          </tbody>
        </table>
      </div>
      <div className="row">

        </button>
        <button type="button" className="btn" onClick={() => setEntries([...rows, blank('swap')])}>
          Add swap

        <span className="spacer" />

          Mount attached devices
        </button>
        <button type="button" className="btn" onClick={() => setAction('generate')}>
          Generate config
        </button>
      </div>

      <NetChange change={run} short={short} helpTopic={HELP.systemMounts} show={action !== null} />
    </div>
  )
}
```

```python
"""LuCI's Status › Firewall (iptables) view (v1.0a2 D6): the legacy rules per table, as LuCI lists and parses them
(luci-mod-status view/status/iptables.js)."""

from __future__ import annotations

import re
from typing import Literal

from pydantic import BaseModel, ConfigDict

Program = Literal["iptables", "ip6tables"]
TABLES = ("filter", "nat", "mangle", "raw")
PROGRAMS: dict[Program, str] = {"iptables": "/usr/sbin/iptables", "ip6tables": "/usr/sbin/ip6tables"}
ZERO: dict[Program, str] = {"iptables": "iptables -Z", "ip6tables": "ip6tables -Z"}
RESTART = "/etc/init.d/firewall restart"
RESET_NOTE = "Resets the filter table's counters only, as LuCI does: nat, mangle and raw keep theirs."
_POLICY = re.compile(r"Chain (.+) \(policy (\w+) (\d+) packets, (\d+) bytes\)")
_REFS = re.compile(r"Chain (.+) \((\d+) references\)")
_ADDR = r"!?[a-f0-9:.]+(?:/[a-f0-9:.]+)?"
_RULE = re.compile(
    rf"(\d+) +(\d+) +(\d+) +(.*?) +(\S+) +(\S*) +(\S+) +(\S+) +({_ADDR}) +({_ADDR})(?: +(.*))?"
)
_COMMENT = re.compile(r"/\* (.*?) \*/")


class IptRule(BaseModel):
    model_config = ConfigDict(frozen=True)

    num: int
    packets: int
    bytes: int
    target: str
    prot: str
    opt: str
    inp: str
    out: str
    source: str
    destination: str
    options: str
    comment: str | None


class IptChain(BaseModel):
    model_config = ConfigDict(frozen=True)

    name: str
    policy: str | None  # built-in chains; user chains have references instead
    packets: int | None
    bytes: int | None
    references: int | None
    rules: list[IptRule]


class IptTable(BaseModel):
    model_config = ConfigDict(frozen=True)

    program: Program
    table: str
    chains: list[IptChain]
    error: str | None = None


class IptablesPresence(BaseModel):
    model_config = ConfigDict(frozen=True)

    iptables: bool
    ip6tables: bool


class IptablesState(BaseModel):
    model_config = ConfigDict(frozen=True)

    iptables: bool
    ip6tables: bool
    tables: list[IptTable]


def listing(program: Program, table: str) -> str:
    if program not in PROGRAMS or table not in TABLES:
        raise ValueError(f"LuCI lists {', '.join(TABLES)} with iptables or ip6tables, not {program} {table}")
    return f"{program} --line-numbers -w -nvxL -t {table}"


def _rule(m: re.Match[str]) -> IptRule:
    options = (m.group(11) or "").strip()
    comment = _COMMENT.search(options)
    return IptRule(
        num=int(m.group(1)),
        packets=int(m.group(2)),
        bytes=int(m.group(3)),
        target=m.group(4),
        prot=m.group(5),
        opt=m.group(6),
        inp=m.group(7),
        out=m.group(8),
        source=m.group(9),
        destination=m.group(10),
        options=_COMMENT.sub("", options).strip(),
        comment=comment.group(1).removeprefix("!fw3: ") if comment else None,
    )


def parse_listing(text: str) -> list[IptChain]:
    heads: list[IptChain] = []
    rules: list[list[IptRule]] = []
    for line in text.splitlines():
        stripped = line.strip()
        if m := _POLICY.fullmatch(stripped):
            heads.append(IptChain(name=m[1], policy=m[2], packets=int(m[3]), bytes=int(m[4]), references=None, rules=[]))
            rules.append([])
        elif m := _REFS.fullmatch(stripped):
            heads.append(IptChain(name=m[1], policy=None, packets=None, bytes=None, references=int(m[2]), rules=[]))
            rules.append([])
        elif heads and (m := _RULE.fullmatch(line.rstrip())):
            rules[-1].append(_rule(m))
    return [h.model_copy(update={"rules": r}) for h, r in zip(heads, rules, strict=True)]
```

```python
"""Legacy iptables (v1.0a2 D6): read LuCI's listings; Reset counters and Restart firewall through the plain apply."""

from __future__ import annotations

from openwrtgui.fw.iptables import (
    PROGRAMS,
    RESET_NOTE,
    RESTART,
    TABLES,
    ZERO,
    IptablesPresence,
    IptablesState,
    IptTable,
    Program,
    listing,
    parse_listing,
)
from openwrtgui.luci_bridge.depends import files_command, parse_ls
from openwrtgui.net.apply import ApplyRunner, NetApplyResult, NetCheck, NetPlan, Planned, net_plan
from openwrtgui.store.routers import RouterRecord, RouterStore
from openwrtgui.transport.base import Transport
from openwrtgui.transport.pool import ConnectionPool

SCREEN = "Firewall"


def _filter_totals(text: str) -> tuple[int, int]:
    """(bytes counted, rules) in a filter listing: the proof of a reset and of a restart."""
    chains = parse_listing(text)
    counted = sum((c.bytes or 0) + sum(r.bytes for r in c.rules) for c in chains)
    return counted, sum(len(c.rules) for c in chains)


class IptablesService:
    def __init__(self, *, pool: ConnectionPool, routers: RouterStore, runner: ApplyRunner) -> None:
        self._pool = pool
        self._routers = routers
        self._runner = runner

    def _record(self, router_id: str) -> RouterRecord:
        rec = self._routers.get(router_id)
        if rec is None:
            raise ValueError(f"Unknown router {router_id}")
        return rec

    async def _presence(self, t: Transport) -> IptablesPresence:
        files = parse_ls((await t.run(files_command(list(PROGRAMS.values())))).stdout)
        return IptablesPresence(
            iptables=files.get(PROGRAMS["iptables"]) == "executable",
            ip6tables=files.get(PROGRAMS["ip6tables"]) == "executable",
        )

    def _programs(self, p: IptablesPresence) -> list[Program]:
        return [prog for prog, there in (("iptables", p.iptables), ("ip6tables", p.ip6tables)) if there]

    async def presence(self, router_id: str) -> IptablesPresence:
        return await self._presence(await self._pool.get(self._record(router_id)))

    async def state(self, router_id: str) -> IptablesState:
        t = await self._pool.get(self._record(router_id))
        p = await self._presence(t)
        tables: list[IptTable] = []
        for program in self._programs(p):
            for table in TABLES:
                r = await t.run(listing(program, table))
                error = None if r.ok else ((r.stderr or r.stdout).strip() or f"exit {r.exit_status}")
                tables.append(IptTable(program=program, table=table, chains=parse_listing(r.stdout) if r.ok else [], error=error))
        return IptablesState(iptables=p.iptables, ip6tables=p.ip6tables, tables=tables)

    async def _plan(self, rec: RouterRecord, t: Transport, which: str) -> NetPlan:
        p = await self._presence(t)
        if not p.iptables:
            raise ValueError(f"{rec.name} has no iptables: fw4's rules are under Raw ruleset")
        reset = which == "reset"
        return net_plan(
            router_id=rec.id,
            screen=SCREEN,
            config=None,
            ops=[],
            current={},
            commands=[ZERO[prog] for prog in self._programs(p)] if reset else [RESTART],
            warnings=[RESET_NOTE] if reset else [],
        )

    async def plan_reset(self, router_id: str) -> NetPlan:
        rec = self._record(router_id)
        return await self._plan(rec, await self._pool.get(rec), "reset")

    async def plan_restart(self, router_id: str) -> NetPlan:
        rec = self._record(router_id)
        return await self._plan(rec, await self._pool.get(rec), "restart")

    async def _apply(self, router_id: str, which: str, digest: str | None) -> NetApplyResult:
        rec = self._record(router_id)
        filter_list = listing("iptables", "filter")

        async def make(t: Transport) -> Planned:
            plan = await self._plan(rec, t, which)
            before = _filter_totals((await t.run(filter_list)).stdout)

            async def verify(t2: Transport) -> list[NetCheck]:
                after = _filter_totals((await t2.run(filter_list)).stdout)
                if which == "reset":
                    ok = before[0] == 0 or after[0] < before[0]
                    return [NetCheck("Counters reset", ok, f"filter: {before[0]} → {after[0]} bytes")]
                return [NetCheck("Rules back", after[1] == before[1], f"filter: {after[1]} rules")]

            return Planned(plan, verify)

        return await self._runner.run_planned(rec, make, digest)

    async def apply_reset(self, router_id: str, digest: str | None) -> NetApplyResult:
        return await self._apply(router_id, "reset", digest)

    async def apply_restart(self, router_id: str, digest: str | None) -> NetApplyResult:
        return await self._apply(router_id, "restart", digest)
```

## v1.0a3 outline: the VLAN editor (planned after Dmitry confirms D1)

LuCI's **Network › Switch/VLAN config** (`admin/network/switch-vlan`, `view/network/switch-vlan.js` at 8b5f528),
built native as Dmitry chose ("VLAN editor only"). Simulator only, because the bench has no DSA router.

| Part | What | Size |
|---|---|---|
| Model | The first `device` of type `bridge` with `vlan_filtering='1'` or a `bridge-vlan` naming it, as LuCI's `findActiveBridge` picks it. Member ports are the union of the device's `ports`, the live bridge ports and the ports in its bridge-vlans; only switch (DSA) or ethernet ports. Each `bridge-vlan` has `vlan` (1-4094, unique), `local` and `ports` (`name` untagged, `name:t` tagged; reads `:u`, `:*`, `:u*`). | M |
| Rules (LuCI's) | Refuse the whole page, as LuCI does, on an unsupported config: a VLAN outside 1-4094, an unparsable port, `t*`, tagged and untagged in one VLAN, `*` without untagged, a port untagged in two VLANs. Making a port untagged in a VLAN takes it out of its old untagged VLAN and keeps tagged memberships. `local` is written `'0'`/`'1'` explicitly (netifd's default is true). Writes only `bridge-vlan` sections, never the device's `ports` or `vlan_filtering`. Removing a VLAN that an interface uses (`<bridge>.<vid>`) is refused, where LuCI does not check. | M |
| Apply | The existing rpcd rollback (`net_plan(config="network", rollback=True)`, `ApplyRunner`), with a verify that reads `bridge vlan show` (or `ubus call network.device status`) back. The own-port lock: a change that leaves the PC's port (by ARL or the bridge FDB) without untagged or PVID membership in the VLAN that carries the app's interface is refused before the preview; the rollback is the second line of defence. | L |
| Simulator | `ap5`, "AP5 · DSA image": board.json `network.lan.ports` (`lan1`..`lan4`), a `device` `br-lan`/`switch` with `vlan_filtering '1'` and `bridge-vlan` sections, DSA port devices in `network.device status`, and a bridge-vlan branch in `SimNetwork.reachable()` so a wrong change really cuts the app off until the rollback. Not seeded by default, like `ap4`. | M |
| Screen | The Ports screen gains a "VLANs (bridge)" view on DSA routers (`PortsState` unmanaged by swconfig today): the VLAN × port matrix of untagged / tagged / PVID, add and remove VLAN, the `local` switch. Front-panel link state, port enable and mirroring on DSA stay 1.x. NATIVE: `admin/network/switch-vlan` → `ports`. | M |
| Docs | Ports.md "VLANs on a DSA router", spec §5 (the editor, not the full DSA backend), CHANGELOG. | S |
