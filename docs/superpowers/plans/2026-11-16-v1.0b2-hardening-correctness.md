# v1.0b2 Hardening I-b: correctness Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close v1.0's open correctness items: places where the app shows, proves, keeps or refuses the wrong thing.
They come from the deferred minors of the v0.4 to v1.0a3 ledgers, plus four of v1.0b1's final review. The plan also
proves Bench Guard at HTTP for every write endpoint that has no such test yet.

**Architecture:** No new subsystem. Each task is a local fix with its own test, in the module that owns the
behaviour. There are three small shared changes:
- the audit log tells listeners about each line it writes for a router (Task 1);
- `MonitorLeases` remembers which phy it holds the monitor for (Task 8);
- `LteService` gets one AT lock per router (Task 11).

**Tech Stack:** Python 3.13, FastAPI, pydantic 2, pytest (asyncio auto), ruff (line 110, `S` on), mypy strict,
React 19, vitest, TanStack Query.

**Spec:** `docs/superpowers/specs/2026-11-03-openwrt-gui-design.md`:
- §6 Safety: the audit log, Bench Guard and the write path;
- the screen sections each task touches: Firewall, Faults, Wi-Fi step-through, RF live, System, Flash, LTE and Ports;
- ROADMAP v1.0, "Hardening".

## Global Constraints

- **Test first:** a change without a test that failed before it is not done (AGENTS.md).
- **Reads:** background reads use `t.run` directly, never `run_audited`. Every read constant passes
  `is_read_only_command`. This plan adds no read command. The recorded AP2 commands (`tests/fixtures/ap2/*.json`)
  replay by exact string, so no existing command text changes.
- **Writes:** every write goes through `ApplyRunner.run_planned` or `run_audited`; values put into a command match a
  `re.fullmatch` rule first and are shell-quoted. Bench Guard refuses writes during a harness run (`GuardLocked`,
  423). This plan adds no write command.
- **No router access:** nothing in this plan runs on AP2 or any bench router (D14).
- **GitHub:** nothing is pushed and no GitHub object is created without Dmitry's explicit go. Branches are never
  deleted.
- **Public repo:** no real keys, passwords, names, neighbour MACs or SSIDs in fixtures, tests or docs. Test MACs are
  `02:00:00:…` (locally administered) or the simulator's own. Test passwords are made up.
- **Scripts** run inside `D:\Essence_SC` or `C:\Essence_SC` (SentinelOne).
- **Style:**
  - ruff line length 110, ruff `S` rules on, mypy strict, functions under 50 lines.
  - Source and test comments name no person: they cite "the final review", a ledger or a date.
- **API model changes:** run `uv run python tools/dump_openapi.py && cd frontend && npm run gen:api` after one (Tasks 3
  and 5 add a field; Task 11 adds bounds).
- **CHANGELOG:** one line per task under `[Unreleased]` › `### Fixed`.
- **pytest groups:** `tests/unit/wifi` and `tests/unit/api` have conftest modules that clash when mixed in one pytest
  call. Run them as separate commands, as the v1.0b1 ledger records; the full suite from the root is fine.

A split into b2 and b3 would only add a review and a PR. |
| D2 | **LuCI facts are dropped after every audited line about a router** (#58). `AuditLog` gets `on_record` listeners, called with the router id after each line it writes for a router; the LuCI bridge's `forget_facts` is one. **Why there:** every change the app makes reaches the audit log, from all twenty writing services, so one place covers them all. `ApplyRunner.on_applied` is removed: it is a subset of this. **The cost:** verify and override lines drop the facts too, which means one extra facts read (six SSH reads) on the next LuCI page list. |
| D3 | **LuCI's menu `depends` are checked as `dispatcher.uc` does** (#53 b-e). This was confirmed against LuCI master's `check_fs_depends`, `check_uci_depends*` and `check_acl_depends`. **(b)** A uci spec that is neither `true` nor an object, and an fs kind LuCI does not know, are not checked: they hide nothing. **(c)** An option matches as LuCI matches it: a list by membership, a single value exactly, so `'a b'` is one value and not two. The facts therefore keep `uci show`'s values as printed (`'a' 'b'` versus `'a b'`) and split them only when comparing. **(d) `executable` passes any regular file. Dmitry's call.** LuCI reads `stat(path).user_exec`, but ucode's `fs.stat` keeps that bit under `.perm`, so LuCI never sees the bit as false and shows the page for any file. No AP2 page depends on an executable that lacks u+x, so nothing on the bench changes. *The other choice:* keep requiring u+x, which hides a page LuCI shows. **(e)** An access group defined with a `read` or `write` key counts even when that part is `{}`: LuCI tests the key's presence. |
| D4 | **Legacy iptables** (#61, #62). **Reset counters is proven per program** (iptables and ip6tables): some counter that counted before (a rule's, or a built-in chain's policy) must be lower after. Counters only grow between resets, so a lower one proves a reset happened, even after a second reset with traffic in between. **Lines the parser cannot read** are counted per table (`IptTable.skipped`), and the tab says "N lines not shown". |
| D5 | **Firewall** (#1, #5, #10, #11). **(#1)** When a run starts between a confirmed runtime table change and its fw4 include, the answer says "Applied at runtime; not saved as an fw4 include: Bench Guard went live (…)", not 423. **(#5)** Table-level one-line statements (`flags dormant`, `comment "…"`) survive an edit. **(#10) IPv6: Dmitry's call.** Addresses stay IPv4 or IPv6, since fw4 takes both. The message becomes "is not an IP address or network". A rule with family `ipv4` or `ipv6`, and an IP set of either family, refuses an address of the other family. *The other choice:* IPv4 only, as the old message said, which removes IPv6 rules the app writes today. **(#11)** An IP set entry has one field per match, separated by spaces (`10.0.0.1 80` for `src_ip dest_port`). Each field is checked by its own match. |
| D6 | **Faults** (#8). A record in `/tmp/owg` that cannot be read (bad JSON, a missing field, a wrong type) is skipped and counted, not raised. `FaultsState.unreadable` is the count, and the screen says "N fault records on the router could not be read". Clear everything still removes the app's table and filters. It leaves such a record in place, because its id cannot be known. |
| D7 | **Step-through** (#40, #41, #42, #45, #46, and two of v1.0b1's minors). **(#40)** A run never stays in a running phase: an error inside the restore ends it as `failed` with Restore offered, and so does a cancelled task, through a `finally`. **(#41)** A proven step is kept in the results and the CSV whatever ends its wait. **(#42)** Next acts only on the phase on screen: each wait clears a Next left from the one before. **(#45)** Restore refuses while a System job or a flash holds the router, as Start does. **(#46)** A saved file without every saved option restores nothing and says which options are missing. **(minors)** Start checks the radio name before it looks for a saved file; `RadioIn` uses `RADIO.pattern`. |
| D8 | **One `owgmon0` per router, held for one phy at a time** (#39). **Dmitry's call.** While the monitor is held for phy0, a holder that needs phy1 is refused with `MonitorBusy`. The beacon check then reads "not checked: owgmon0 is on phy0 for capture 3", not a result from the wrong radio. *The other choice:* one monitor per phy (`owgmon0` for phy0, `owgmon1` for phy1, so phy0's recordings stay valid). When several are enabled, an SSH change is refused: "Cannot tell which SSH instance this app uses on AP2: the interface list could not be read. Try again." **(#37)** A router counts as gone after three failed logins in a row, not one. **(#38)** The password policy is read and checked under the write lock. |
| D10 | **Flash and tools** (#14, #15, #20). `FlashPlan` carries its steps by name (`image_name`, `validate_command`, `test_command`, `sysupgrade_command`). ## Review Focus

1. **A step-through that breaks while it restores.** An exception inside the restore, or a cancelled task, must end
   the run as `failed` with Restore offered and the router free for the next job. Today it can stay "restoring" and
   block the router until the app restarts. Task 6 tests both.
2. **A firewall table with table-level lines.** `flags dormant` and a table `comment` must survive an edit of one of
   its chains, and the include must say what it saved. Task 4 tests the round trip.
3. **An IP set with two matches.** For `src_ip dest_port`, `10.0.0.1 80` passes, `10.0.0.1` alone and `80 10.0.0.1`
   are refused with the field that is wrong, and an IPv6 entry is refused in an `ipv4` set. Task 4 tests each.
4. **Two users of the monitor on two radios.** A capture on phy0 and a beacon check on phy1: the beacon check must say
   "not checked", never report beacons heard on phy0. The capture keeps its monitor. Task 8 tests the leases and the
   beacon check.
5. **LuCI's page list after a change the app made outside the apply runner.** A Wi-Fi apply, an AT write or a password
   change: the next page list reads the facts again. Task 1 tests a Wi-Fi apply and a password apply through the
   context.

```python
def skipped_lines(text: str) -> int:
    """Lines `parse_listing` shows nothing for: not a chain head, the column header, a rule or blank."""
    return sum(
        1
        for line in text.splitlines()
        if line.strip()
        and not _POLICY.fullmatch(line.strip())
        and not _REFS.fullmatch(line.strip())
        and not _HEADER.fullmatch(line.strip())
        and not _RULE.fullmatch(line.rstrip())
    )


def _counters(text: str) -> dict[tuple[str, int], int]:
    """Every byte counter in a listing: (chain, 0) for a built-in chain's policy, (chain, n) for rule n."""
    out: dict[tuple[str, int], int] = {}
    for chain in parse_listing(text):
        if chain.bytes is not None:
            out[(chain.name, 0)] = chain.bytes
        out |= {(chain.name, r.num): r.bytes for r in chain.rules}
    return out


def reset_proven(before: str, after: str) -> bool:
    """Counters only grow between resets: one that counted before and is lower now proves the reset, also after
    an earlier reset with traffic since (v1.0b2 D4). Nothing counted before: nothing to prove."""
    was, now = _counters(before), _counters(after)
    counted = {key: n for key, n in was.items() if n > 0}
    return not counted or any(now.get(key, 0) < n for key, n in counted.items())
```

```python
class MonitorBusy(ValueError):
    """owgmon0 is held for another radio: one monitor never answers for two (v1.0b2 D8)."""


class MonitorLeases:
    def __init__(self) -> None:
        self._holders: dict[str, list[str]] = {}
        self._locks: dict[str, asyncio.Lock] = {}
        self._generations: dict[str, int] = {}
        self._phys: dict[str, str] = {}  # router id -> the phy owgmon0 is on while it is held

    def _same_phy(self, router_id: str, holder: str, phy: str) -> None:
        held = self._phys.get(router_id)
```

```python
GONE_AFTER = 3  # failed logins in a row: one alone may be a lost packet, not firstboot (v1.0b2 D9)


async def _logs_in(pool: ConnectionPool, rec: RouterRecord) -> bool:
    try:
        t = await pool.fresh(rec)
    except TransportError:
        return False
    try:
        return (await t.run("true")).ok
    except TransportError:
        return False
    finally:
        with contextlib.suppress(TransportError):
            await t.close()


async def wait_until_gone(
    pool: ConnectionPool,
    rec: RouterRecord,
    *,
    armed_at: float,
    clock: Callable[[], float],
    sleep: Callable[[float], Awaitable[None]],
    every_s: float,
    limit_s: float = RESET_LIMIT_S,
) -> bool:
    """True once new logins at the router's address fail GONE_AFTER times in a row (firstboot took it away),
    False after limit_s."""
    await pool.drop(rec.id)
    failed = 0
    while clock() - armed_at < limit_s:
        await sleep(every_s)
        failed = 0 if await _logs_in(pool, rec) else failed + 1
        if failed >= GONE_AFTER:
            return True
    return False
```

```python
        try:
            return self._read(path, board)
        except (OSError, ValueError, ValidationError):
            log.warning("the tool cards in %s cannot be read", path.name)
            return []

    def _kept(self, board: str) -> list[ToolCard]:
        """The cards a save or delete starts from. A file that cannot be read is moved aside first, so a write
        never replaces cards it could not read (v1.0b2 D10)."""
        path = self._file(board)
        if not path.is_file():
            return []
        try:
            return self._read(path, board)
        except (OSError, ValueError, ValidationError):
            aside = path.with_name(f"{path.name}.damaged-{datetime.now():%Y%m%d-%H%M%S}")
            path.replace(aside)
            log.warning("moved the unreadable %s aside as %s", path.name, aside.name)
            return []

    def save(self, card: ToolCard) -> None:
        check_card(card)
        self._write(card.board, [*(c for c in self._kept(card.board) if c.path != card.path), card])

    def delete(self, board: str, path: str) -> None:
        self._write(board, [c for c in self._kept(board) if c.path != path])
```
