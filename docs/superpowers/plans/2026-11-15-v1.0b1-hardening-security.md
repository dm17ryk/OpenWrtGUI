# v1.0b1 Hardening I-a: security Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close v1.0's open security items: one secret matcher for every place the app shows option values, the
SIM PIN kept off the AT console, router-supplied names and backup archives checked before they reach a command,
Bench Guard proven at HTTP for v1.0a2's writes, bandit rules and dependency audits in CI, and `SECURITY.md` saying
what the app does and does not protect. The AP2 window of 2026-11-15 left two small fixes; they ride along.

**Architecture:** No new subsystem. A small `guard/secrets.py` holds the one matcher (`is_secret_option`,
`shown`) that Discovery, Plugins and the LuCI bridge use; the audit log keeps its exact-name command masking. A small
`ifname.py` holds the interface-name rule that RF, the monitor and the step-through already share in spirit. The rest
are local fixes with a test each, a ruff config change, one new GitHub workflow and documentation.

**Tech Stack:** Python 3.13, FastAPI, pydantic 2, pytest (asyncio auto), ruff (line 110, now with `S`), mypy
strict, pip-audit, React 19, vitest, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-03-openwrt-gui-design.md`:
- §6 Safety (audit log and secret masking, Bench Guard, write path);
- §7.12 System access (the app key; rotation is not built);
- the open-item table (O7, O10, O11, O12, O17, O20's HTTPS part);
- ROADMAP v1.0, "Hardening".

## Global Constraints

- **Test first:** a change without a test that failed before it is not done (AGENTS.md).
- **Reads:** background reads use `t.run` directly, never `run_audited`. Every read constant passes
  `is_read_only_command`. This plan adds no read and changes no read command's text: the recorded AP2 commands
  (`tests/fixtures/ap2/*.json`) replay by exact string.
- **Writes:** every write goes through `ApplyRunner.run_planned` with a `net_plan` preview; every value put into a
  command matches a `re.fullmatch` rule first and is shell-quoted; Bench Guard refuses writes during a harness run
  (`GuardLocked`, 423). This plan adds no write.
- **No router access.** Nothing in this plan runs on AP2 or any bench router (D13).
- **GitHub:** nothing is pushed and no GitHub object is created without Dmitry's explicit go. Branches are never
  deleted.
- **Public repo:** no real keys, PINs, passwords, names, neighbour MACs or SSIDs in fixtures, tests or docs. Test
  PINs are `1234`/`5678`; test keys are made up. A backup archive holds secrets: never one in a fixture, log or
  commit.
- **Scripts** run inside `D:\Essence_SC` or `C:\Essence_SC` (SentinelOne).
- **Style:** ruff line length 110, mypy strict, functions under 50 lines. Source and test comments name no person:
  they cite "the final review" or a date.
- **API model changes:** run `uv run python tools/dump_openapi.py && cd frontend && npm run gen:api` after one
  (Task 5 changes `FstabGlobal`).
- **Manual headings:** a new or renamed heading means updating `frontend/src/help/topics.ts`; `manual.test.ts`
  checks every topic is a heading.
- **CHANGELOG:** lines go under `[Unreleased]`, in a `### Security` group (new) or `### Fixed`.

The image is the user's own file and its import runs in a worker thread, so this bounds a mistake rather than an attack. |

```python
"""Which uci options hold a secret, for every place the app shows option values: Discovery, Plugins and a
bridged LuCI change (v1.0b1 D2). The audit log masks commands with the exact names only."""

from __future__ import annotations

import re

HIDDEN = "<hidden>"
SECRET_OPTIONS = (
    "key",
    "key1",
    "key2",
    "key3",
    "key4",  # WEP
    "password",
    "pincode",
    "psk",
    "sae_password",
    "multi_ap_backhaul_key",  # a Wi-Fi passphrase
    "auth_secret",
    "acct_secret",
    "dae_secret",
    "auth_server_shared_secret",
    "acct_server_shared_secret",
    "priv_key_pwd",
    "priv_key2_pwd",
    "private_key_passwd",
    "private_key2_passwd",
    "wps_pin",
    "ap_pin",
    "r0kh",
    "r1kh",  # FT key holders carry their keys
    "private_key",
    "preshared_key",  # WireGuard
)
# A substring on purpose: third-party plugin options are run together (`apikey`, `totpsecret`).
_SECRET_PART = re.compile(r"key|secret|pass|psk|token|pin|pwd", re.IGNORECASE)
# Flags whose value is exactly what a person should see: whether password login is on (dropbear).
_SHOWN = frozenset({"PasswordAuth", "RootPasswordAuth"})


def is_secret_option(name: str) -> bool:
    """`name` is a bare option (`key`) or a `uci show` path (`wireless.default_radio0.key`). A path of two parts
    is a section and its type, never an option."""
    parts = name.split(".")
    if len(parts) == 2:
        return False
    option = parts[-1]
    if option in _SHOWN:
        return False
    return option in SECRET_OPTIONS or _SECRET_PART.search(option) is not None


def shown(name: str, value: str | None) -> str | None:
    """The value as the app shows it: hidden for a secret option; None stays None."""
    return HIDDEN if value is not None and is_secret_option(name) else value
```

```python
def _entries(root: Any, name: str) -> dict[str, Any]:
    out: dict[str, Any] = {}
    unpacked = 0
    try:
        for seen, entry in enumerate(root.root.riter(), start=1):
            if seen > MAX_ENTRIES:
                raise ImageError(f"{name} holds more than {MAX_ENTRIES} entries")
            try:
                path = entry.path
            except UnicodeDecodeError:
                continue
            if path != "/" and not entry.is_dir:
                if entry.is_file:
                    unpacked += entry.size
                    if unpacked > MAX_UNPACKED:
                        raise ImageError(f"{name} unpacks to more than {MAX_UNPACKED // 2**20} MiB")
                out[path] = entry
    except ImageError:
        raise
    except Exception as exc:  # a damaged squashfs can fail anywhere inside the reader
        raise ImageError(f"{name}: the root file system could not be read ({exc})") from exc
    return out
```

```python
"""Waiting for a router to settle before an as-found check (AP2 window 2026-11-15)."""

from __future__ import annotations

import asyncio
from collections.abc import Awaitable, Callable


async def settled[T](
    read: Callable[[], Awaitable[T]],
    want: T,
    *,
    tries: int = 15,
    pause_s: float = 1.0,
    sleep: Callable[[float], Awaitable[None]] = asyncio.sleep,
) -> T:
    """Reads until a read equals `want` or `tries` reads were made; returns the last read."""
    got = await read()
    for _ in range(tries - 1):
        if got == want:
            break
        await sleep(pause_s)
        got = await read()
    return got
```
