# v1.0a1 LuCI parity I Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Each router lists only the LuCI pages LuCI itself would show there, with the reason for the ones it would
not. Status › Realtime Graphs › Wireless opens RF live. The manual's out-of-date pages are corrected, and AP2's
flash refusal (O17) is written down.

**Architecture:** `parse_menu` keeps LuCI's raw `depends` for a page and its ancestors. A pure evaluator
(`luci_bridge/depends.py`) checks them against facts read from the router: one `ls -ldL` of the named paths,
`ls -A` of each named directory, `uci -q show` of each named config, and the router's ACL groups. It follows
LuCI's `dispatcher.uc` rules. `LuciBridgeService.pages()` marks each page `available` or not, with a `missing`
reason. The simulator answers these reads from a per-router file map. The frontend counts only available fallback
pages and lists the rest under "Not on this router".

**Tech Stack:** Python 3.13, FastAPI, pydantic 2, pytest (asyncio auto), ruff (line 110), mypy strict, React 19,
TanStack Query, vitest, Playwright e2e on the simulator.

**Spec:** `docs/superpowers/specs/2026-11-03-openwrt-gui-design.md`: §8 (LuCI parity table), §7.14 (LuCI
fallback), §12 and ROADMAP v1.0 ("Native screens for every LuCI page on the bench image (the fallback stays for
pages that later images bring)"), D13, §13 O17. The scope comes from Dmitry's v1.0 answers on 2026-11-12:

## Review Focus

1. **The facts cannot be read** (an old busybox without `ls -L`, which exits 1 like "all paths missing"; `ls` not
   found; a dropped connection). The page list must stay as it is today: nothing hidden, no error, and
   `checked=False`. → Task 2 `test_missing_paths_are_the_ones_ls_names`, Task 3
   `test_unreadable_facts_hide_nothing` (both cases).
2. **A later image's menu names a path with a space or a shell character** (`/usr/share/my app/x`). The command
   must quote it, and the parser must read it back whole. → Task 2 `test_paths_are_quoted_and_read_back_whole`.
3. **A symlinked binary** (`/usr/sbin/iptables -> xtables-nft-multi`). It must count as executable, as LuCI's
   `stat` follows it. → Task 2 `test_a_symlink_counts_as_what_it_points_to` (the `-L` listing shows the target's
   mode under the link's name).
4. **A page whose own depends pass under a parent whose depends fail** (`admin/network/firewall/zones` without
   `/sbin/fw3`). It must be hidden, with the parent's reason. → Task 2 `test_an_unsatisfied_parent_hides_its_pages`.
5. **A stale link to a hidden page** (a bookmark to `/routers/ap2/luci?page=admin%2Fsystem%2Fmounts`). The app
   must answer 422 with the reason, not open a bridge to LuCI's 404. → Task 3
   `test_opening_a_page_luci_hides_is_refused`.

```python
@dataclass(frozen=True)
class LuciPage:
    path: str
    title: str
    package: str
    acl: tuple[str, ...]
    uci: tuple[str, ...]
    fs: tuple[str, ...]
    section: str = ""  # the menu entries above the page, below "admin": "Network › Firewall"
    # LuCI's raw `depends` of each menu entry above the page and of the page itself, ancestors first
    # (dispatcher.uc stops at an unsatisfied node); read by luci_bridge/depends.py
    requires: tuple[dict[str, Any], ...] = field(default=(), compare=False)
```

Add a helper above `parse_menu`, and pass `requires` when building each page:

```python
def _requires(path: str, depends_of: Mapping[str, dict[str, Any]]) -> tuple[dict[str, Any], ...]:
    parts = path.split("/")
    chain = ("/".join(parts[:n]) for n in range(1, len(parts) + 1))
    return tuple(depends_of[p] for p in chain if p in depends_of)
```

In `parse_menu`, after `titles = {...}`:

```python
    depends_of = {
        path: entry["depends"]
        for entries in menus.values()
        for path, entry in entries.items()
        if isinstance(entry, dict) and isinstance(entry.get("depends"), dict) and entry["depends"]
    }
```

and in the `LuciPage(...)` call add `requires=_requires(path, depends_of),` after `section=...`.

### Task 2: The depends evaluator (LuCI's rules, pure)

**Files:**
- Create: `src/openwrtgui/luci_bridge/depends.py`
- Test: `tests/unit/luci/test_depends.py`

**Interfaces:**
- Consumes: `LuciPage.requires` (Task 1).
- Produces:
  - `Facts(files: Mapping[str, str], uci: Mapping[str, Mapping[str, str]], acl: frozenset[str], checked: bool = True)`
  - `UNCHECKED: Facts` (nothing read, `checked=False`)
  - `fs_paths(pages) -> list[str]`, `dir_paths(pages) -> list[str]`, `uci_configs(pages) -> list[str]`
  - `files_command(paths) -> str`, `listing_command(path) -> str`, `uci_command(config) -> str`
  - `parse_ls(text) -> dict[str, str]`, `missing_paths(stderr, paths) -> set[str]`
  - `usable_groups(acl) -> frozenset[str]`
  - `why_hidden(page, facts) -> str | None`
  - File kinds are `"file" | "executable" | "directory" | "empty directory" | "other"`.

These rules were checked against AP2's recordings with a throwaway prototype while writing this plan. They hide
exactly the five pages in Task 4, with the reasons Task 3's tests expect.

```python
def test_fs_kinds() -> None:
```

```python
"""Which LuCI pages LuCI itself shows on a router (v1.0a1 D2): its menu's `depends`, checked the way LuCI's
dispatcher.uc does, against facts the app reads from the router (D3)."""

from __future__ import annotations

import re
import shlex
from collections.abc import Iterable, Iterator, Mapping
from dataclasses import dataclass
from typing import Any

from openwrtgui.probe.luci_menu import LuciPage

_CONFIG = re.compile(r"[A-Za-z0-9_-]+")


@dataclass(frozen=True)
class Facts:
    # present paths -> "file", "executable", "directory", "empty directory" or "other"
    files: Mapping[str, str]
    # config -> parse_uci_show of `uci -q show <config>`; a config missing here is absent
    uci: Mapping[str, Mapping[str, str]]
    # the router's LuCI access groups that grant read or write
    acl: frozenset[str]
    # False: the facts could not be read, so nothing is hidden (D3)
    checked: bool = True


UNCHECKED = Facts({}, {}, frozenset(), checked=False)


def _alternatives(value: Any) -> list[dict[str, Any]]:
    if isinstance(value, dict):
        return [value]
    return [v for v in value if isinstance(v, dict)] if isinstance(value, list) else []


def _fs_alternatives(pages: Iterable[LuciPage]) -> Iterator[dict[str, Any]]:
    return (alt for page in pages for d in page.requires for alt in _alternatives(d.get("fs")))


def fs_paths(pages: Iterable[LuciPage]) -> list[str]:
    return sorted({p for alt in _fs_alternatives(pages) for p in alt})


def dir_paths(pages: Iterable[LuciPage]) -> list[str]:
    return sorted({p for alt in _fs_alternatives(pages) for p, kind in alt.items() if kind == "directory"})


def uci_configs(pages: Iterable[LuciPage]) -> list[str]:
    names = {c for page in pages for d in page.requires for alt in _alternatives(d.get("uci")) for c in alt}
    return sorted(n for n in names if _CONFIG.fullmatch(n))


def files_command(paths: Iterable[str]) -> str:
    return "ls -ldL " + " ".join(shlex.quote(p) for p in sorted(set(paths)))


def listing_command(path: str) -> str:
    return f"ls -A {shlex.quote(path)}"


def uci_command(config: str) -> str:
    if not _CONFIG.fullmatch(config):
        raise ValueError(f"{config!r} is not a uci config name")
    return f"uci -q show {config}"


def parse_ls(text: str) -> dict[str, str]:
    """Busybox `ls -ldL` lines: mode, links, owner, group, size, month, day, time or year, then the name.
    A device's size is two columns ("1,   3")."""
    out: dict[str, str] = {}
    for line in text.splitlines():
        fields = 10 if line[:1] in ("b", "c") else 9
        parts = line.split(None, fields - 1)
        if len(parts) < fields or len(parts[0]) < 10:
            continue
        mode, name = parts[0], parts[-1]
        if mode[0] == "d":
            out[name] = "directory"
        elif mode[0] == "-":
            out[name] = "executable" if mode[3] in "xs" else "file"
        else:
            out[name] = "other"
    return out


def missing_paths(stderr: str, paths: Iterable[str]) -> set[str]:
    """Paths busybox `ls` says do not exist ("ls: /sbin/block: No such file or directory"). The listing counts
    only when every path is listed or named here (D3); any other `ls` message leaves the facts unread."""
    lines = set(stderr.splitlines())
    return {p for p in paths if f"ls: {p}: No such file or directory" in lines}


def _fs_ok(path: str, kind: str, files: Mapping[str, str]) -> bool:
    have = files.get(path)
    if kind == "absent":
        return have is None
    if kind == "executable":
        return have == "executable"
    if kind == "file":
        return have in ("file", "executable")
    if kind == "directory":
        return have == "directory"
    return False


def _fs_reason(alt: Mapping[str, str], files: Mapping[str, str]) -> str:
    path, kind = next((p, k) for p, k in alt.items() if not _fs_ok(p, k, files))
    return f"is for routers without {path}" if kind == "absent" else f"needs {path}"


def _sections(config: str, values: Mapping[str, str]) -> dict[str, tuple[str, dict[str, str]]]:
    """{section id: (type, options)} from `uci -q show` lines (`network.@switch[0]=switch`, `network.lan=…`)."""
    out: dict[str, tuple[str, dict[str, str]]] = {}
    for key, value in values.items():
        parts = key.split(".", 2)
        if parts[0] != config or len(parts) < 2:
            continue
        kind, options = out.get(parts[1], ("", {}))
        if len(parts) == 2:
            out[parts[1]] = (value, options)
        else:
            options[parts[2]] = value
            out[parts[1]] = (kind, options)
    return out


def _section_ok(kind: str, options: Mapping[str, str], spec: Any) -> bool:
    if spec is True:
        return bool(options)
    if isinstance(spec, str):
        return kind == spec
    if isinstance(spec, dict):
        for name, want in spec.items():
            have = options.get(name)
            if have is None:
                return False
            if want is not True and str(want) != have and str(want) not in have.split():
                return False
        return True
    return False


def _uci_alt_ok(alt: Mapping[str, Any], uci: Mapping[str, Mapping[str, str]]) -> bool:
    for config, spec in alt.items():
        sections = _sections(config, uci.get(config, {}))
        if spec is True:
            if not sections:
                return False
            continue
        if not isinstance(spec, dict):
            return False
        for name, section_spec in spec.items():
            if name.startswith("@"):
                if not any(k == name[1:] and _section_ok(k, o, section_spec) for k, o in sections.values()):
                    return False
            elif name not in sections or not _section_ok(*sections[name], section_spec):
                return False
    return True


def _uci_reason(alt: Mapping[str, Any]) -> str:
    config, spec = next(iter(alt.items()))
    if spec is True or not isinstance(spec, dict):
        return f"needs the {config} configuration"
    name, section_spec = next(iter(spec.items()))
    if not name.startswith("@"):
        return f"needs {config}.{name}"
    if isinstance(section_spec, dict):
        wanted = ", ".join(f"{k}={'set' if v is True else v}" for k, v in section_spec.items())
        return f"needs a {name[1:]} section in {config} with {wanted}"
    return f"needs a {name[1:]} section in {config}"


def _reason(depends: Mapping[str, Any], facts: Facts) -> str | None:
    for group in depends.get("acl") or ():
        if group not in facts.acl:
            return f"needs LuCI's {group} access group"
    fs = _alternatives(depends.get("fs"))
    if fs and not any(all(_fs_ok(p, k, facts.files) for p, k in alt.items()) for alt in fs):
        return _fs_reason(fs[0], facts.files)
    uci = _alternatives(depends.get("uci"))
    if uci and not any(_uci_alt_ok(alt, facts.uci) for alt in uci):
        return _uci_reason(uci[0])
    return None


def why_hidden(page: LuciPage, facts: Facts) -> str | None:
    """None when LuCI shows the page on this router; else why not (an ancestor's reason first)."""
    if not facts.checked:
        return None
    for depends in page.requires:
        reason = _reason(depends, facts)
        if reason is not None:
            return reason
    return None


def usable_groups(acl: Mapping[str, Mapping[str, Any]]) -> frozenset[str]:
    """Access groups LuCI counts: defined with a read or a write part (check_acl_depends)."""
    return frozenset(name for name, d in acl.items() if d.get("read") or d.get("write"))
```

```python
"""A simulated router's files, as far as LuCI's menu asks about them (v1.0a1 D7): `ls -ldL` and `ls -A`."""

from __future__ import annotations

import shlex
from collections.abc import Mapping

from openwrtgui.transport.base import CommandResult

_MODES = {
    "executable": "-rwxr-xr-x",
    "file": "-rw-r--r--",
    "directory": "drwxr-xr-x",
    "empty directory": "drwxr-xr-x",
    "other": "prw-r--r--",  # a FIFO: the same columns as a file (a device's size would be "major, minor")
}


class SimFiles:
    def __init__(self, files: Mapping[str, str]) -> None:
        self._files = dict(files)

    def answer(self, command: str) -> CommandResult | None:
        if command.startswith("ls -ldL "):
            paths = shlex.split(command)[2:]
            lines = [
                f"{_MODES[self._files[p]]}    1 root     root          4096 Aug 13  2024 {p}"
                for p in paths
                if p in self._files
            ]
            missing = [p for p in paths if p not in self._files]
            stderr = "".join(f"ls: {p}: No such file or directory\n" for p in missing)
            return CommandResult(command, "".join(f"{line}\n" for line in lines), stderr, 1 if missing else 0)
        if command.startswith("ls -A "):
            path = shlex.split(command)[2]
            kind = self._files.get(path)
            if kind not in ("directory", "empty directory"):
                return None  # not a directory this map knows: the other handlers or the recordings answer it
            return CommandResult(command, "entry\n" if kind == "directory" else "", "", 0)
        return None
```

```python
def page_views(pages: Sequence[LuciPage], facts: Facts | None = None) -> list[PageView]:
    # LuCI hides one of two same-titled pages by its dependencies; the label tells them apart either way.
    counts = Counter(_label(p) for p in pages)

                p.path,
                p.title,
                p.package,
                NATIVE.get(p.path),
                p.section,

                available=missing is None,
                missing=missing,
                checked=facts.checked if facts is not None else True,
            )
        )
    return views
```
